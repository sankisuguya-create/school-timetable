# 操作説明動画（教員向け）の作成要件

ユーザーが求める演出ルール（厳密に守ること）:

1. **字幕は操作に先行させる**。説明を先に出し、操作が終わるまで出し続ける。
2. **操作ごとにタイトルカード**を挿入する。「操作名＋目的ひとこと」、できれば「操作 n/N」の番号付き。
3. **カーソルは大きく視認性の高い色**（太めの黄色矢印、約58px）。
4. **ゆっくり操作**する（苦手な教員向け）。カーソル移動・クリックのペースを落とす。
5. **クリック前にクリックポイントの周囲をカーソルで2周**して対象を強調（リング描画も併用）。ただし**同じ場所を連続でクリックするときは最初の1回だけ**周回し、2回目以降は周回しない。**カーソル操作を伴わない「ここを見て」の指し示しでも周回する**（1周）。
6. **拡大表示（拡大窓）は定位置（右上）を基本**にし、見せたいポイントや開いているポップアップ・ダイアログと重なるときだけ別の隅へ退避させる。**ポイント周辺の文字が小さい時や複雑なUIの時だけ使う**（何でも拡大しない）。窓に「拡大」などのラベル文字は付けない。
7. **印刷プレビュー等では字幕・拡大窓を印刷内容に重ねない**：プレビューを開く直前に字幕と拡大窓を消し、閉じたら再開する。
8. **チカチカさせない**：`Page.captureScreenshot` をコンポジット経由（デフォルト）で連打すると画面が白く欠ける。拡大窓の中身は `fromSurface:false` で窓面全体を取り、Python側でcrop+拡大する（dprで座標変換）。
9. **音声ナレーションは付けない**（求められた場合のみ別途相談）。**動画再現が難しい操作は、字幕だけの説明でもよい**（ユーザー承認済み）。
10. **出力はMP4 1本・字幕・タイトル焼き込み**。公開リポジトリならGitHub Releaseのアセットに置いてダウンロードURLを渡す（日本語ファイル名はGitHubが`_`に変換するのでASCII名にする）。

## 実装の置き場所（/home/ubuntu/demo）

- `overlay.js` … ページに注入する演出レイヤ（字幕・タイトルカード・大カーソル・リング・拡大窓 `DEMO.sub/title/cursor/ring/mag`）。`<dialog[open]>` 内にオーバーレイを再配置する MutationObserver あり。
- `driver.py` … CDP接続（`localhost:29229`）・クリック注入（`click_el`。連続同所クリックは `_last_click` で2回目以降の周回を抑制）・「見て」用 `point_el`（周回1回→リング）・ドラッグ&ドロップ `drag_to`（26ステップの eased mouseMoved で HTML5 DnD を発火）・拡大窓ループ（`_mag_loop`）・印刷プレビューを xdotool の `key Escape` で閉じる `esc_until_closed`。
- `scenes.py` … 場面の進行。録画は `ffmpeg -f x11grab -i :0.0 -draw_mouse 0`。

## school-timetable 固有の注意

- `dist/index.html` を `file://` で開く（localStorage利用・ログイン不要）。本番データに触らず撮れる。
- 印刷プレビューが開いている間はページtargetのCDP応答が全部止まる。dispatch系は `wait_for(2.2)` で包み、プレビューはOS側の `xdotool key Escape` で閉じる。
- `#tyCopy` を押すと `#tallyDlg` は自動で閉じる（閉じるボタンのクリックは不要）。
- 教科チップは選択中セルがあればクリックだけで確定する。別セルへ移す前に `clearSelection`。
- `scrollIntoView` は「見えていないときだけ・`block:'nearest'`」にしないと画面が跳ねてチラつく。
- 日本語フォントが無い環境では先に `fonts-noto-cjk` を入れる（blueprint提案済み）。
- 「たんぽぽに提出」ボタンは `Yr.tanpopo`（組→クラスの並び）に児童がいるクラスでだけ出る。ローカル撮影では `school-timetable/v3/y/<年>` のJSONに `tanpopo:{"1":["3-1"]}` 等を書き込んでリロードして仕込める。`Backend.tpSubmit` は file:// でも端末内保存で動く。
- 学年・全校の面（gateの `[data-go="grade"]`/`[data-go="school"]`）は編集できる単一シートで、入れた予定は各クラスの週案に「3年学活」等として反映される。**チップの持ち上げは JS の `.click()` では発火しない** — `Input.dispatchMouseEvent`（CDPの本物クリック、driverの `click_el`）を使う。
- リンク貼り：セル選択→`#pTitle`/`#pNote`/セル`.t` `.n` の文字を Range で選択（`lastRange` が残る）→ `#pAddLink` → `#linkDlg` でURL→`#linkGo`。
