# school-timetable

教職員が1つの週案を共同で編集し、**B5で刷って教務必携に貼る**。
あわせて、たんぽぽ時間割（特別支援学級）への反映と、
時数集計表（Excel）へのコピーを1操作で出す。

西宮市立高木北小学校の運用に合わせてある。

| ファイル | 内容 |
|---|---|
| [`docs/spec.md`](docs/spec.md) | **仕様の正本。まずここを読む** |
| [`docs/setup.md`](docs/setup.md) | **置き方の手順。** 上から順にやる |
| `src/` | **直すのはこちら。** 12節に置き方 |
| `dist/index.html` | ブラウザで開ける生成物。ダブルクリックで動く |
| [`gas/`](gas/) | Apps Script 側。関門・シート・読み書きまで |
| `tools/` | ブラウザで動かして確かめる |

```
python3 build.py          src/ から dist/index.html と gas/plan.html を作る
python3 build.py --check  生成物が src と一致するか調べる
node tools/check.mjs      画面を動かして確かめる（56件）
node tools/wirecheck.mjs  本番の口とのやりとりを確かめる（27件）
node gas/storecheck.js    シートの読み書きを確かめる（57件）
node gas/gatecheck.js     関門を確かめる（29件）
```

## 手元と本番

**画面はどちらで動いているかを知らない。** `src/js/backend.js` が吸収する。

| | 手元（`dist/index.html` を開く） | 本番（Apps Script） |
|---|---|---|
| 置き場所 | ブラウザの中 | スプレッドシート |
| 読み | しない | 開く年度と週を1回だけ |
| 書き | 丸ごと | **差分をまとめて送る** |

1コマ打つたびにサーバを待つ作りにしていない。校内の回線では打鍵が止まる。

## 決めてあること

- **開いたものが層を決める。** `3-3` を開けばそのクラス、`3年` なら学年の全クラス、
  `全学年` なら全クラス、`音楽` なら専科の自分の週。
  「だれとして書くか」を別に選ばせない
- **勝つのは最後に書かれたもの。** 層は出どころの表示だけで、勝ち負けを決めない。
  層の順で決めると、上位があとから入れた予定が下位に負けて、入れた本人にも見えない
- **誰でもどのコマでも直せる。** 重なりは開いたとき1回だけ知らせる
- **クラス編成は表から読む。** 学年でクラス数が違う（5年・6年だけ4クラス）
- **勝ち負けの時刻はサーバが打つ。** 教師それぞれの PC の時計を信じると、
  時計が進んでいる人がいつも勝つ
- **年度は 4/1 起点で日付から決まる。** 前の年度は丸ごと残る
- **白い紙に出ているものだけが刷られる。** まわりの操作は刷られない。
  紙の上下には何も置かない（置くたびに紙が縮む）
- **上書きは両側に知らせる。** 書く側には書く前に1回、された側には次に開いたときに
- **クラス名は日付に化ける。** `1-1` は「1月1日」。列を書式なしテキストにし、
  化けていたら月-日から戻す
