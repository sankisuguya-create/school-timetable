# school-timetable

教職員が1つの週案を共同で編集し、**B5で刷って教務必携に貼る**。
あわせて、たんぽぽ時間割（特別支援学級）への書き出しと、
時数集計表（Excel）へのコピーを1操作で出す。
たんぽぽへは**1週ぶんを1枚のシート**（「9月1週」）として出す。
シートは**週の順**（4月→翌3月）に増えていく。

西宮市立高木北小学校の運用に合わせてある。

| ファイル | 内容 |
|---|---|
| [`docs/spec.md`](docs/spec.md) | **仕様の正本。まずここを読む** |
| [`docs/setup.md`](docs/setup.md) | **置き方の手順。** 上から順にやる |
| `src/` | **直すのはこちら。** 12節に置き方 |
| `dist/index.html` | ブラウザで開ける生成物。ダブルクリックで動く |
| [`gas/`](gas/) | Apps Script 側。関門・シート・読み書きまで |
| `tools/` | ブラウザで動かして確かめる |
| `tools/make-ai-bundle.py` | サンドボックスを見られない外部AIへ渡す、コード一式を1ファイルに束ねる |

```
npm install               検査に playwright が要る（1回だけ）
python3 build.py          src/ から dist/index.html と gas/plan.html を作る
python3 build.py --check  生成物が src と一致するか調べる
node tools/check.mjs      画面を動かして確かめる（363件）
node tools/wirecheck.mjs  本番の口とのやりとりを確かめる（253件）
node gas/storecheck.js    シートの読み書きを確かめる（338件）
node gas/gatecheck.js     関門を確かめる（27件）
node gas/apicheck.js      関門の呼び忘れ・呼び先の行方不明を見る（79件）
```

外部AIへコードを渡し直すときは、`python3 tools/make-ai-bundle.py` を実行する。
Git管理されている正本・検査・文書を、元ファイル名つきで `EXTERNAL_AI_BUNDLE.md` にまとめる。
この生成物は追跡しない（`.gitignore` 済み）。渡すたびに作り直せば、古いコードを渡す事故が起きない。
`dist/index.html` と `gas/plan.html` は生成物なので収録せず、外部AIには `src/` を直すよう伝える。

**この6つが通らないものはデプロイしない。**

## 手元と本番

**画面はどちらで動いているかを知らない。** `src/js/backend.js` が吸収する。

| | 手元（`dist/index.html` を開く） | 本番（Apps Script） |
|---|---|---|
| 置き場所 | ブラウザの中 | スプレッドシート |
| 読み | しない | 開く年度と週を1回だけ |
| 書き | 丸ごと | **差分をまとめて送る** |

1コマ打つたびにサーバを待つ作りにしていない。校内の回線では打鍵が止まる。

## 決めてあること

- **開いたものが層を決める。** `3-3` を開けばそのクラス、`3年` なら学年の全クラス、
  `全学年` なら全クラス、`音楽` `外国語` なら専科の自分の週。
  「だれとして書くか」を別に選ばせない
- **勝つのは最後に書かれたもの。** 層は出どころの表示だけで、勝ち負けを決めない。
  層の順で決めると、上位があとから入れた予定が下位に負けて、入れた本人にも見えない
- **誰でもどのコマでも直せる。** 重なりは開いたとき1回だけ知らせる
- **クラス編成は表から読む。** 学年でクラス数が違う（5年・6年だけ4クラス）
- **勝ち負けの時刻はサーバが打つ。** 教師それぞれの PC の時計を信じると、
  時計が進んでいる人がいつも勝つ
- **年度は 4/1 起点で日付から決まる。** 前の年度は丸ごと残る
- **白い紙に出ているものだけが刷られる。** まわりの操作は刷られない。
  紙の上下には何も置かない（置くたびに紙が縮む）
- **その日の形（ふつう／特別校時／休み）は全学年の面から決める。**
  特別校時はその日の朝学習が消えて上へ詰まり、休みは1〜6に斜め線が入る。
  戻せば書いてある予定がそのまま出る（休みにしても中身は消していない）
- **曜日は月〜土の6列。日曜は置かない。** 土は行事だけで、ほとんど空く。
  土の列は 20mm に留めてあるので、月〜金の幅は変わらない
- **A週B週は日付から決まる。** 起点の月曜（2026-09-07＝A週）から1週ごとに入れ替わる。
  手で選ばせると、選び忘れた人だけ別の基本時間割を見ることになる
- **用紙は mm で書く。** CSS の `size:B5` は ISO B5（176×250mm）で、
  日本の B5（182×257mm）ではない。キーワードで書くと白紙の2ページ目が付く
- **上書きは両側に知らせる。** 書く側には書く前に1回、された側には次に開いたときに
- **クラス名は日付に化ける。** `1-1` は「1月1日」。列を書式なしテキストにし、
  化けていたら月-日から戻す
- **書き込みのあいだは、全面にかぶせて次の操作を受け付けない。**
  保存・たんぽぽ出力・年度の検査と退避。週を開く読み込みは止めない
  （止めると、開いたのに何も出ない時間ができる）
- **Ctrl+Z で一手戻せる。** 書き込みは1本道なので、そこで直前の中身を控える。
  欄の中の Ctrl+Z はブラウザに任せる（打ち間違いを1字だけ直せなくならない）
- **4週ぶんを 2×2 で見る面がある**（月で見る）。B4 のよこ1枚に刷る。
  組み立ては週の紙と同じもので、詰めるのは高さだけ。**見るだけの面**で、
  直すのは週の紙のほう
- **いま見ている週は、左メニューを転がしても左上に残る。**
  ここを見失うと、書いた先を間違える
- **教科の色は、画面の教科チップにだけ敷く。** 紙の上には出さない
  （紙のコマの地は「層」を表し、しかもモノクロで刷る）。
  チップの色は識別を担わない ── 教科名の字が担う
- **たんぽぽへ出してよいかは、担任が押して決める。** 1コマでも書いてあれば
  済、にはしない。ちょっと触っただけの週と、出してよい週を、たんぽぽ担当が
  見分けられなくなる。印は**週ごとに立て直す**
- **たんぽぽの出す先は1本とはかぎらない。** 画面から足す・消す・変える。
  消すのは一覧の行だけで、向こうのファイルには手を出さない
- **左の並びには「？」がある。** 押すと、その項目が何で、押すと何が起きて、
  はじめての人がどこでつまずくかが1つの窓に出る
- **窓を閉じる ✕ は、窓枠の右上の角**（窓の中ではない）。中に置くと、
  中身の1行目と同じ高さに並んで、読むものと閉じるものが混ざる
- **新しい年度の準備は、手順として出す。** 4/1 から、ぜんぶ済むまで
  左メニューに出る。**元に戻せない操作はぜんぶで1つだけ**（前の年度の行を消す）で、
  そこには必ず突き合わせが入る。ほかは間違えてもやり直せる

## 直し方（何年か先の自分と、次の担当者へ）

**1. 本番の Apps Script エディタで直さない。**
GitHub のこのリポジトリが正本。エディタで直すと、次に誰かが `clasp push` や
貼り直しをした時点で黙って消える。消えたことにも気づかない。
急ぎで本番を直した場合は、**その日のうちに同じ直しを src に入れて push する**。

**2. `dist/index.html` と `gas/plan.html` を直さない。**
どちらも `src/` から `build.py` が作る生成物。直しても次のビルドで消える。
直すのは `src/` のほう。

**3. 出す前に、版を上げる。**
`VERSION` の `version:` と `date:` を手で書き替えてから `python3 build.py`。
ビルドした日を自動で埋めない（生成物が日ごとに変わり、`--check` が翌日落ちる）。
版は画面左下「管理・システム」に出る。**不具合の連絡は、この窓の1行をそのまま貰う。**

**4. 出す前に、6つ全部を通す。**
上の表のコマンドを上から順に。`build.py --check` が「一致している」と言わない
まま貼ると、教員が見ている画面と手元の src が別物になり、以後の調査が全部狂う。

**5. 関門を足したら検査も足さない（自動で見る）。**
サーバ関数を1つ足したら、1行目に `Gate.check()` を書く。書き忘れは
`node gas/apicheck.js` が名指しで落とす。画面から呼ぶ名前の綴り違いも同じ。

## 管理用のシートは、一般の教員に共有しない

週案の**スプレッドシート本体**（設定・クラス・専科・基本時間割・週案 …）は、
**管理者3名だけの編集権限**にする。教員はウェブアプリの URL だけを使う。

| | 渡すもの | 権限 |
|---|---|---|
| 教員（30人ほど） | ウェブアプリの URL | シートには直接アクセスさせない |
| 管理者（3人） | スプレッドシートの URL | 編集者 |

理由は2つ。

- ウェブアプリは `executeAs: USER_DEPLOYING` で動く。**教員はシートの権限を
  持たなくても週案を書ける。** 権限を配る必要がそもそも無い
- 「設定」シートには関門の例外リストがある。ここを直せる人が増えるほど、
  児童を弾く仕組みが弱くなる

**設定・クラス・専科・時程・教科**の各シートは、シートの保護（範囲を保護し、
管理者3名だけ編集可）を掛ける。週案シートはスクリプトが書くので保護しない
（保護すると `USER_DEPLOYING` の書き込みまで止まる場合がある）。
置き方は [`docs/setup.md`](docs/setup.md)。

## 年度末に、前年度を退避する

年に1回・10分。**本体のURLは変わらない。** 新年度も教員は同じURLを開く。

1. 管理・システム →「年度の退避」→ **数える**
2. ドライブでファイルを**丸ごと複製**し（人の手）、名前を `週案 保存 2025年度` にしてURLを貼る
3. **照合する**（シートごとの行数・コマ数が合わなければ、1行も消さない）
4. 年度を打ち込んで **本体から消す**（週案のその年度の行だけ。シートも基本時間割も残る）

複製をコードで書かないので、**コピー漏れが原理的に起きない**。
退避した年度を開くと、紙の上に「退避ずみ」の帯と保管庫へのリンクが出る。
手順は [`docs/setup.md`](docs/setup.md) Step 8.5。
