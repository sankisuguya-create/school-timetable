# 置き方の手順

校務用の Google アカウントで、上から順にやる。
**各段の「確かめる」を飛ばさない。** 飛ばすと、あとの段で原因を切り分けられなくなる。

所要はだいたい 60〜90 分（Step 5 の実測を含む）。
仕様の理由は [`spec.md`](spec.md)。

---

## Step 0. 先に決めておくこと

| | |
|---|---|
| 誰が置くか | **教務**（この人のアカウントでスクリプトが動き、この人だけがシートを持つ） |
| どこに置くか | 校務用ドライブの、教職員だけが入れるフォルダ |
| 児童は入れない | ドメインで弾く。設定ではなくコードが弾く（Step 6） |

---

## Step 1. スプレッドシートを作る

1. 校務用ドライブに新しいスプレッドシートを作る。名前は `週案 2026年度` など
2. **共有を先に決める。** 右上「共有」→
   - **「特定のユーザー」で教職員だけ**
   - 「リンクを知っている全員」「組織内の全員」に**しない**
3. ウェブアプリは「置いた人として実行」するので、**ほかの教職員にシートの権限は要らない**

> **ここがいちばん忘れられる。** 関門があっても、シートが児童に共有されていれば
> アプリを迂回して全部読める。

**確かめる**：ほかの先生のアカウントでシートのURLを開き、「アクセス権が必要です」と出ること。

### 誰に何を渡すか

| | 渡すもの | 権限 |
|---|---|---|
| 教員（30人ほど） | **ウェブアプリの URL だけ** | シートには入れない |
| 管理者（3人） | スプレッドシートの URL | 編集者 |

**教員にシートの URL を配らない。** ウェブアプリは「置いた人として実行」するので、
教員はシートの権限が無くても週案を書ける。配ると、直接編集して壊れたときに
**誰がどこを触ったか分からなくなる**（週案シートはスクリプトが全面を書き替える形なので、
手で足した行は次の保存で消える）。

### 管理者だけが直せるようにする

次の5枚は**範囲を保護して管理者3名だけ編集可**にする。
シートのタブを右クリック →「シートを保護」→ 権限を設定 → 3名だけ。

| シート | 保護する理由 |
|---|---|
| `設定` | **関門の例外リストがここにある。** 直せる人が増えるほど児童を弾く力が落ちる |
| `クラス` | 学級編成。1行消えるとそのクラスが入口から消える |
| `専科` | 同上 |
| `時程` | 全校の版面が変わる |
| `教科` | 教科コードが変わると、入っているコマの教科が外れる |

**`週案 …` の各シートは保護しない。** スクリプトが書き替えるので、
保護すると保存が止まることがある。ここは「最後に書かれたものが勝つ」で運用する。

## Step 2. スクリプトを貼る

1. 拡張機能 → Apps Script
2. ⚙ プロジェクトの設定 →「**`appsscript.json` マニフェスト ファイルをエディタで表示する**」にチェック
   - **先にやる。** 後回しにするとタイムゾーンとデプロイ設定を書けない
3. ファイルを作って、リポジトリの中身を貼る

   | 種類 | 名前 | 中身 |
   |---|---|---|
   | マニフェスト | `appsscript.json` | `gas/appsscript.json`（**既存を上書き**。新規作成ではない） |
   | スクリプト | `Gate` | `gas/Gate.gs` |
   | スクリプト | `Sheets` | `gas/Sheets.gs` |
   | スクリプト | `Store` | `gas/Store.gs` |
   | HTML | `plan` | `gas/plan.html` |

   拡張子は付けない。`gatecheck.js` `storecheck.js` `README.md` は**貼らない**。

4. `Gate.gs` の先頭のドメインが自校のものか見る

   ```js
   const STAFF_DOMAIN  = "edu.nishi.or.jp";   // 教職員
   const STUDENT_LOCAL = /^[0-9]{8}$/;        // 児童は @ の左が8桁の数字
   ```

**確かめる**：手元で `node gas/gatecheck.js`（26件）・`node gas/apicheck.js`（48件）・`node gas/storecheck.js`（175件）が通ること。
**通らないまま貼らない。**

## Step 3. シートを作る

1. エディタで関数 `setupSheets` を選んで実行
2. 初回は「このアプリは Google で確認されていません」が出る。
   詳細 →「（プロジェクト名）に移動（安全ではないページ）」で進む
3. シートが9枚できる

   `設定` `時程` `クラス` `専科` `教科` `基本時間割` `週案` `年設定` `固定時間割取り込み`

4. 続けて関数 `setupPlanSheets` を実行する。
   **クラスごとの週案シート**（`週案 3-3` `週案 3年` `週案 全校` …）ができる

   > 週案は**1クラス1枚**。1枚に全クラスを積むと、担任がシートを開いても
   > どの行が自分のものか分からない。中は**日付順**に並ぶ（並べ替えは自動）。

5. 旧版から移すときだけ、関数 `migratePlanSheets` を1回実行する。
   1枚だった `週案` シートの中身が、クラスごとのシートへ移る。
   **何度実行しても同じ。** 旧シートは消さない

**何度実行しても同じ。** すでにあるシートには触らない。

**確かめる**：`クラス` シートの「クラス」列が **書式なしテキスト**になっていること
（表示形式 → 書式なしテキスト にチェック）。

> **クラス名は日付に化ける。** `1-1` は「1月1日」、`6-3` は「6月3日」として
> 取り込まれる。打ち込んでもスクリプトから入れても同じ。
> `setupSheets` がこの列を書式なしテキストにするので化けなくなる。
> すでに化けている値も、読むときに月-日から元に戻す。

## Step 4. 学校のかたちを入れる

シートを実物に合わせる。**ここがこのシステムの正本。コードには書かない。**

### クラス

1行1クラス。`年度` を空にすると「どの年度でも使う既定」になる。

| 年度 | 学年 | クラス | 担任メール | たんぽぽ交流級 |
|---|---|---|---|---|
| | 1 | 1-1 | | ○ |
| | 1 | 1-2 | | |
| … | | | | |
| | 5 | 5-4 | | |
| | 6 | 6-4 | | ○ |

高木北小は **1〜4年が3クラス、5年・6年が4クラス（20学級）**。
年度で編成が変わったら、その年度の行を足す（前の年度の行はそのまま残す）。

`たんぽぽ交流級` は、**たんぽぽ児童がいる交流学級**の印。
空でなければ何を書いても印になる（`○` `1` `あり` …）。外すときは**空にする**。
画面のたんぽぽの面から選んでも、この欄に書き戻される。どちらから直してもよい。

> 画面から学級編成を直しても、**`担任メール` と 専科の `メール` は消えない**（引き継ぐ）。

### 専科・教科・時程

- `専科`：音楽・図工・理科・外国語など。`教科コード` は `教科` シートのコードに合わせる
- `教科`：**時数に数えない教科（行事・給食・クラブ・委員会）は「時数表の1文字」を空にする**。
  書くと Excel 側の出現数の集計が増える
- `時程`：各校時の時刻。**画面には出るが、紙には出ない**（版面を動かさないため）

### 年設定

| 年度 | 第1週の月曜 |
|---|---|
| 2026 | 2026-04-06 |

時数集計表のシート名（週番号）の起点になる。

**確かめる**：`設定` の `例外で通すメール` は、8桁の数字が本名のアドレスに
なっている職員がいるときだけ書く。**教職員ドメインの中でしか効かない。**

## Step 5. 紙を合わせる ← いちばん大事

**ここが合わないと、以降の機能は全部無駄になる。**

1. デプロイ前でよいので、手元で `dist/index.html` をブラウザで開く
2. どれか1つのクラスを開き、左の「印刷（B5）」
3. **B5で刷って教務必携の週案枠に当てる**
4. 合わなければ「用紙・印刷」で余白と印刷倍率を動かし、もう一度刷る
5. 合った値を `設定` シートに書く

   | キー | 値 |
   |---|---|
   | 印刷用紙 | B5 |
   | 印刷余白mm | （合った値） |
   | 印刷倍率 | （合った値） |

**確かめる**：刷った紙が枠の上にきれいに貼れること。全職員が同じ値を使うこと。

## Step 6. ウェブアプリとして出す

1. デプロイ → 新しいデプロイ → 種類は**ウェブアプリ**
2. **次のユーザーとして実行：自分**
3. **アクセスできるユーザー：同じ組織内の全員**

`appsscript.json` に `executeAs: USER_DEPLOYING` / `access: DOMAIN` を書いてあるので
画面の既定もこの組み合わせになる。**それでも一度目は目で確かめる。**
ここを「アクセスしているユーザーとして実行」にすると、
開いた人の権限でシートに書くことになり、全員に編集権限が渡る。

> `access: DOMAIN`（組織内の全員）は、**児童が同じテナントにいれば児童も含む**。
> 入口を絞っているのは `Gate.gs` であって、この設定ではない。

### 児童アカウントで必ず試す

デプロイした URL を **児童アカウント1つで実際に開く**。

| 出るはず | |
|---|---|
| 「この週案は先生用です。」 | 通っている |
| 週案が見えた | **そこで止める。** `Gate.check()` を呼んでいないサーバ関数を探す |

呼び忘れは手で探す前に `node gas/apicheck.js` を回す。
サーバ関数を1つずつ児童のアドレスで叩いて、止まらないものを名指しする。

`/exec` の URL を使う。エディタの「テスト用デプロイ」で取れる `/dev` は
編集権限のある人しか開けないので、児童アカウントでの確認に使えない。

---

### 年度の初めに1回、検査する

左メニュー下の「管理・システム」→「**この年度を検査する**」。
クラス・担任のメール・専科・時程・基本時間割・年設定・たんぽぽ・週案シートの8つを見て、
**足りないものだけを名指しする**。

| 出方 | 意味 |
|---|---|
| 要る | そのままでは担任が使えない。直してから配る |
| 見る | 使えるが、後で困る。心当たりを確かめる |
| よい | そろっている |

**直しはしない。** 黙って直すと、直した中身が誰にも見えないまま年度が進む。
直し方は各行の下に書いてある。

## Step 7. 基本時間割を入れる

1. ウェブアプリを開く → 左の「基本時間割」
2. クラスと A週／B週 を選んで、各コマの教科を入れる
3. A週とB週がほとんど同じなら「A週をB週へ写す」→ 違うところだけ直す

**これが入っていると、週案を開いた時点で全コマに出る。**
担任は毎週30コマ埋めるのではなく、変えたところだけ直す。

学校の固定時間割表がそのままあるなら、**「表から取り込む」**のほうが速い
（1行1クラス・各校時がA週B週の2列の表を、そのまま貼る）。

年度が変わったら、「前年度から写す」で去年の形から始められる
（クラス編成と専科は自動で引き継ぐが、**基本時間割は引き継がない**）。

### シートに直接書くとき

`基本時間割` シートは人が直接書いてよい。1行1コマ。

| 年度 | クラス | 週 | 曜日 | 時程 | 教科コード | 表示名 |
|---|---|---|---|---|---|---|
| 2026 | 1-1 | A | 月 | p1 | kokugo | 国語 |
| 2026 | 1-1 | B | 月 | p1 | kokugo | 国語 |

- **曜日は「月」〜「金」**（「月曜日」でも、古い書き方の `0`〜`4` でも読む）
- **時程は `p1`〜`p6`**（`1`〜`6` と書いても、授業の行の上から数えて読む）
- `週` は `A` か `B`。**A週とB週は別の行**。同じなら同じ内容で2行書く
- `教科コード` は `教科` シートのコード。空でもよい（`表示名` が紙に出る）

**読めない行があると、開いたときに「基本時間割シートに読めない行がある」と
何行目かを出す。** 黙って捨てない。

## Step 8. 外へ出す2つを合わせる

### 時数集計表（Excel）

1. 週案を開いて左の「時数をコピー」
2. `貼る先` `クラスの順` `1日ぶんの行数` `列のずれ` を実物に合わせる
3. **1回貼ってみて、ずれていたら「列のずれ」を直す**
4. 合った値を `設定` シートに書く

空のセルも含む1つの矩形なので、左上のセルを選んで**1回貼るだけ**で5日ぶんが揃う。

> 矩形の中に `=IF($A$1="A",Top!…)` の式があれば、貼った時点で値に置き換わる。
> **これは承知の上の置き換え。** A週/B週の流し込みはこちら側が持つので、
> Excel 側の式は要らなくなる。

### たんぽぽ時間割（週に1回、担任の週案がそろってから）

**形が合わないと1コマも入らない。** 手で整えるより、こちらで作ったほうが早い。

1. `設定` の `たんぽぽファイルID` にURLを貼る（手順4）
2. たんぽぽの面 →「**いまの形をみる**」。何行×何列か、日付・骨（中休み・給食・
   昼休み）・交流学級の見出しがあるかを、そのまま出す。足りないものは名指しする
3. 合っていなければ「**この形で作りなおす**」。
   選んだ交流級の**人数ぶんの列**（2人いる交流級は2列）で、1日16行×5日の形を作る。
   授業名の行は灰色、担当者・場所が「た」で始まると白に戻る条件付き書式も入る。
   **いまのシートは消さない**（名前を変えて残す）
4. 列の幅だけ、B4 1枚に収まるようたんぽぽ担当が調える

> 自前で整えるときの決まりは2つだけ。
> **1コマが2行で1組**（上が授業名、下が担当者・場所）。
> 各日のブロックに **「中休み」「給食」「昼休み」** の行があること。
> この3行を骨にして校時の行を数えるので、**行数は揃っていなくてよい**
> （実物の 16・18・15・18・18 行のままでも書ける）。
> **日付は毎回こちらが入れ直す**ので、週ごとに打ち替えなくてよい。
3. **塗り分けの条件付き書式をシート側に入れる。**
   このサイトは値だけ入れて、**色は塗らない**。

   タイトルの行（各コマの上の行）を選び、書式ルール → カスタム数式：

   ```
   =LEFT($B3,1)="た"      ← B3 は「そのセルのすぐ下（担当者・場所）」に合わせる
   ```

   | 当てはまる | 背景 |
   |---|---|
   | 担当者・場所が「た」で始まる（たんぽぽで受ける） | 白 `#FFFFFF` |
   | それ以外 | 灰色 `#DCDCDC` |

   *シート側に置く理由*：入れたあとに、たんぽぽ担当が担当者・場所を `交：` から `た：` へ直す。
   こちらが塗った色は直した瞬間に古くなり、**色と中身が食い違う**。
   シートが自分で塗れば、直した瞬間に色も追いつく。

   モノクロで刷って見分けるための塗り分けなので、色相は使わない。
   `#F2F2F2` まで薄くすると白との差が 1.1 倍しかなく、白黒コピーで消える。
4. `設定` の `たんぽぽファイルID` に、たんぽぽ時間割の**URLをそのまま貼る**。
   `https://docs.google.com/spreadsheets/d/…/edit?…` のままでよい（IDだけ抜いてもよい）。
   1枚目のシート以外に書くときは `たんぽぽシート名` も入れる。
   **これが空だと、押しても何も起きない**（そう画面に出る）
5. ウェブアプリの入口（週案をひらく）→ **いちばん下の「たんぽぽ」**
6. **たんぽぽ児童がいる交流級と人数を選ぶ。** 押すたびに 0人 → 1人 → 2人 → 0人。
   ここが `クラス` シートの `たんぽぽ交流級` 欄と同じもの（`2` と書けば2人。`○` は1人）
   - **たんぽぽ時間割は児童ごとに1列。** 2人いる交流級は2列いる。
     出したあとに「人数と列の数が合っていない」と出たら、列を足すか人数を直す
   - 選んだクラスのうち、**今週まだ基本時間割から動いていないもの**が知らせに出る
   - 出すのを止めはしない。金曜までに全担任が書き終わらない週はある。見えていればよい
7. 「たんぽぽ時間割へ出す」→ 確認 → **書き込む**
8. 出たあとの数を必ず見る。

   | 出るもの | 意味 |
   |---|---|
   | 「◯日ぶん・◯コマ」 | 入った |
   | **「書かなかった日がある」** | **その日は入っていない。** 日ブロックの形が合っていない（手順1・2へ戻る） |
   | 「列見出しにあるが選んでいないクラス」 | たんぽぽ側の見出しか、選んだ交流級のどちらかが古い |

> **書くのは授業名の行だけ。** 担当者・場所の行と、その色（支援員の色分け）には触らない。
> 選んでいない交流級の列・支援員の列・中休み・給食・昼休みの行も触らない。
> 日ブロックの位置は、A列の日付を探して決める（先頭行を決め打ちしない）。

## Step 9. 年間行事計画表

1行1日の縦長の表を `行事取り込み` という名前のシートに貼る。

| 日付 | 週 | 行事計画（児童） | 行事計画（職員） |
|---|---|---|---|
| 2026-11-16 | A | 校外学習6年(奈良) | 職員会議15:00 |

3か月が横に並んだ元の形のままは読ませない。
**月ブロックの開始列を1つ間違えると、別の月の行事が別の日付に静かに入る。**
日付の列があれば読み違えようがない。

## 直すとき

**`dist/index.html` と `gas/plan.html` は直さない。** 直すのは `src/`。

**本番の Apps Script エディタで直さない。** GitHub が正本。
エディタで直したものは、次に誰かが貼り直した時点で黙って消える。
急ぎで本番を直したときは、その日のうちに同じ直しを `src/` に入れて push する。

**出す前に `VERSION` を書き替える。** `version:` と `date:` を手で上げてからビルドする。
版は画面左下「管理・システム」に出る。不具合の連絡は、その窓の1行をそのまま貰う。

```
python3 build.py          src/ から作り直す
python3 build.py --check  生成物が src と一致するか
node tools/check.mjs      画面（Playwright・161件）
node tools/wirecheck.mjs  本番の口とのやりとり（102件）
node gas/storecheck.js    シートの読み書き（175件）
node gas/gatecheck.js     関門（26件）
node gas/apicheck.js      関門の呼び忘れ・呼び先の行方不明（48件）
```

**この6つが通らないものは貼らない。**

Apps Script 側でコードを直したら、
**デプロイを管理 → 鉛筆 → バージョンを「新バージョン」にしてデプロイし直す。**
「直したのに変わらない」の原因はたいていこれ。
「新しいデプロイ」を選ぶと URL 自体が変わるので、同じ URL を保つなら「編集」のほう。

| クラスが `2026/01/01` になっている | その列が書式なしテキストか（Step 3）。読み直せば戻る |
| 週案が保存されない | 画面下に赤い帯が出ていないか。出ていればそこに理由が書いてある |

| どの版が動いているか分からない | 左メニュー下の「管理・システム」。版・版の日付・つないでいるファイル名が出る |

| 基本時間割がサイトに出ない | `基本時間割` シートの `曜日` と `時程`。読めない行があれば開いたときに何行目かを出す（Step 7） |
| 刷った紙が枠に合わない | Step 5 をやり直す。**画面の大きさではなく「印刷の倍率」を動かす** |
| 他の先生の予定が消えた | 消えていない。上書きされただけ。開いたときに知らせが出る（[`spec.md`](spec.md) 3節） |
