# 週案（時間割共同編集） — 仕様の正本

教職員が1つの週案を共同で編集し、**B5で刷って教務必携に貼る**。あわせて、たんぽぽ時間割
（特別支援学級）への反映と、時数集計表（Excel）へのコピーを1操作で出す。

**この文書が仕様の正本。** 実装で迷ったらここに戻る。ここに書いていないことは決まっていない。

優先順位は **エラーの少なさ ＞ 認知的負荷の低さ ＞ 処理速度 ＞ 実装コスト**。
この文書の判断は、迷ったときすべてこの順で決めている。

---

## 0. 何を決めて、何を決めていないか

**凍結（v0 として確定。変えるならこの文書を書き換えてから）**

| | 決めたこと |
|---|---|
| 基盤 | GAS ウェブアプリ。校務ドメインの Google アカウントで認証する（1節） |
| 正本 | 週案スプレッドシート1枚。1行＝1コマ（4節） |
| コマの単位 | `(日付, 時程行, クラス)`。この3つで1コマが一意に決まる |
| コマの中身 | タイトル・詳細の2段。休み行はタイトルのみ |
| 層 | 基本時間割・学校全体・学年・専科・担任の5つ。**層は出どころの表示だけで、勝ち負けは決めない** |
| 勝ち負け | **最新の状態を見たうえで、あとから書いたものが出る。** 時刻で決める（3節） |
| 権限 | **誰でもどのコマでも直せる。** 上位から来たコマは淡い塗りとラベルで示す |
| 上書き（書く側） | **別の人の予定を潰すときだけ**、書く前に1回聞く。基本時間割を直すときは聞かない |
| 上書き（された側） | 自分の予定が上書きされていたら、**次に開いたときに知らせる**。同じ上書きは1回だけ |
| 保存の競合 | 自分が開いたあとに誰かが直していたら、**そのコマは書かずに止めて返す**。窓の既定は「最新の内容を見る」（3節） |
| クラス名 | `1-1` は日付に化ける。**列を書式なしテキストにし、化けていたら月-日から戻す** |
| 基本時間割 | **A週とB週の2種類を持つ。** 週案を開いた時点で全コマに流し込む |
| クラス編成 | **表から読む。コードに書かない。** 学年でクラス数が違う（**5年・6年だけ4クラス**、ほかは3クラス） |
| 年度 | **4/1 起点。開いている週の日付から決まる。** 手で切り替えさせない。**前の年度は丸ごと残る** |
| 行事 | 年間行事計画表から読む。**日付単位で取り込み、校時への割り付けは人がする**（6節） |
| 専科の表記 | 同じコマを、担任は教科名（音楽）で、専科はクラス名（2-1）で見る。データは1つ |
| リンク | **1つのコマにいくつでも。** 選んだ文字に付き、その文字を押すと開く。刷ると下線だけ残る |
| 出力① | たんぽぽ時間割へ「反映」。**選んだ交流級の列は全部書く。担当者・場所の行と色には触れない**（7節） |
| たんぽぽの形 | **日ブロックを16行で揃える**（先頭 2・18・34・50・66、末尾81行）。いまより5行短い |
| たんぽぽの印刷 | **B4 1枚**に収める。列幅はたんぽぽ担当が合わせる |
| 交流か在籍か | **担当者・場所の行（交：／た：／支：）で決める。** 授業名の字は見ない。**塗るのはシート側の条件付き書式**（7節） |
| たんぽぽの入口 | 入口の表のいちばん下。**そこで交流級を選び、そこからだけ出す**。ほかのクラスの画面には置かない（7節） |
| 出力② | 時数集計表へ「クリップボードにコピー」。**空セル込みの1つの矩形**。教科は1文字（8節） |
| 実施と予定 | **分けない。** 週案は1本で持つ |
| 印刷 | B5・1週1ページ。リンクは下線だけにして URL は刷らない |
| 土日 | 1列に畳み、上7行ぶんを土、下3行ぶんを日にする。授業行は持たず、行事だけ書く |
| 色 | 塗りは2色だけ（降ってきた／重なっている）。**層はラベルの文字が運ぶ**。色を外しても意味が残る |
| 入口 | 学年×クラスのグリッド。**開いたものが層を決める**。「だれとして書くか」は選ばせない（9節） |
| 画面 | 左＝メニュー／中＝週案／右＝入力の3列。週案は**画面に自動で合わせる**（9節） |
| 右の幅 | ロック・保存が**折り返さない幅**にする。押すものが2行に散らばると読みにくい |
| 入力 | 教科は右上のパレットから**コマへ引っぱって入れる**。押しても入る |
| 教科の色 | **付けない。** 塗りの2枠は出どころに使う。教科はセルの文字が言っている（9節） |
| 机と紙 | 暗い「机」の上に白い「紙」を置く。**紙の上に出ているものだけが刷られる** |
| 入れる人 | **教職員だけ。児童は弾く。** `@` の右側を完全一致で見る（10節） |

**未決（実物を見てから決める。実装を止めるものではない）**

| | 決めていないこと | 止まるか |
|---|---|---|
| a | 貼り付け領域の実寸（教務必携の週案枠は何 mm × 何 mm か） | 止まらない。倍率と余白を画面から動かせる |
| b | 時数集計表の**列のずれ**（朝・各校時が左上から何列目か）。いまは画像からの推定値 | 止まらない。画面から直せる（8節） |
| c | 時程（各校時が何時からか）と、学年ごとの日課の違い。いまは全学年で同じ既定値 | 止まらない。時程シートで持つ |
| d | 専科の担当割・たんぽぽ児童がいる交流級 | 止まらない。`専科` シートと `クラス` シートの「たんぽぽ交流級」欄で持つ |

## 1. なぜ GAS ウェブアプリなのか

要件のうち3つが、校務ドメインの中でしか成立しない。

| 要件 | ドメイン外のアプリ | GAS ウェブアプリ |
|---|---|---|
| 教職員の共同編集 | 校務アカウントで認証できない | ドメイン内認証がそのまま効く |
| ①たんぽぽ時間割へ反映 | 校務ドライブのシートに書けない | `SpreadsheetApp` |
| 行事の取り込み | 校務ドライブのシートを読めない | `SpreadsheetApp` |
| ②クリップボードへコピー | できる | できる |
| B5印刷 | できる | できる |

`prototypes/src/weekly-plan.html` は**印刷の版面と入力操作を紙で確かめるための元**であって、
運用の本体ではない。ノート評価と同じで、`build.py` が `prototypes/` と `gas/` の両方を作る。

## 2. 版面（画像の左ページに合わせる）

刷ったものを既存の週案枠の上に貼る。だから**枠の形は手帳に合わせる**。

```
        月    火    水    木    金   │土日
      ┌─────┬─────┬─────┬─────┬─────┼──┐
朝休み│     │     │     │     │     │土│  ← タイトルのみ
朝学習│漢字 │読聞 │読書 │漢字 │計算 │  │  ← 曜日ごとに違う。だから列は割る
      ├─────┼─────┼─────┼─────┼─────┤  │
  1   │題名 │題名 │題名 │題名 │題名 │  │
      │┈┈┈┈│┈┈┈┈│┈┈┈┈│┈┈┈┈│┈┈┈┈│  │  ← 上=タイトル 下=詳細
      │詳細 │詳細 │詳細 │詳細 │詳細 │  │
  2   │     │     │     │     │     │  │
      ├─────┼─────┼─────┼─────┼─────┤  │
業間  │     │     │     │     │     │  │
      ├─────┼─────┼─────┼─────┼─────┤  │
  3   │     │     │     │     │     │  │
  4   │     │     │     │     │     ├──┤
      ├─────┼─────┼─────┼─────┼─────┤日│
昼休み│給食・そうじ                     │  │
      ├─────┼─────┼─────┼─────┼─────┤  │
  5   │     │     │     │     │     │  │
  6   │     │     │     │     │     │  │
      ├─────┼─────┼─────┼─────┼─────┼──┤
      │備考 │備考 │備考 │備考 │備考 │  │  ← **備考だけ**（題名の欄を作らない）
放課後│     │     │     │     │     │  │
      │     │     │     │     │     │  │  ← 紙の余りはここに渡す
      ├─────┴─────┴─────┴─────┴─────┴──┤
週メモ│                                    │  ← 放課後に回したぶん、半分
      └────────────────────────────────────┘
```

**放課後は備考だけ。** 教科を入れるところではないので、題名の欄を作らない。
時程シートの `種別` を「備考」にした行が、この形になる。

**紙の余りは放課後に渡す。** 紙の高さは決まっているので、どこかを広げれば
どこかが狭くなる。放課後に書くのは会議や行事で、週メモより行数が要る。
放課後の行が無い年（時程シートに置かない）は、余りが週メモに戻る。

**休み行も曜日ごとのセルにした。** 朝学習は曜日で中身が違う（月＝漢字、火＝計算…）。
帯にすると入らない。代わりに、休み行のコマを選ぶと下の帯に**「全曜日に入れる」**が出る。
給食・そうじのように5日とも同じものは、1回打って1回押せば済む。

**朝学習にも教科を入れられる。** 時数集計表に「朝」の列があり、そこに教科の字が入るため（8節）。

**土日を1列に畳んだのは、そこに授業行が要らないから。** 手帳の左ページも日曜は隅に潰してある。
6日ぶんの授業行を刷ると1列あたりが 4mm 痩せて、詳細欄が使いものにならなくなる。
土のほうを広く取った（上7行ぶん）。**日曜より土曜のほうが書くことが多い。**

### 字の大きさ — 枠いっぱいまで大きく、入らないコマだけ縮める

授業名は**枠に入る限界まで大きく**する（題名の欄 8mm に 16pt）。
「クラブ活動・委員会」のような長い名前は、**そのコマの中だけ**縮む。

*全部を同じ大きさに合わせない理由*：いちばん長い名前に全部を合わせると、
「国語」まで小さくなる。紙に載っているコマの大半は2文字で、
**そこが読めることのほうが、大きさがそろっていることより効く。**
週案は読むための紙であって、見せるための紙ではない。

*刷るときの列の幅で測る理由*：画面の時程の列は時刻を出すぶん広く、
刷るときは狭い（そのぶん曜日の列が 1.2mm ずつ広い）。
画面の幅で決めると、刷れば入るはずの字まで小さくなる。**紙が正本。**

縮める下限は 45%。それ以下にすると読めなくなるので、そこで止めて欄からはみ出させない
（欄の外へは出ない。`overflow:hidden`）。

測るのと書くのは分ける。1コマずつ「書いて測って」を繰り返すと、
そのたびにブラウザが並べ直す（55コマで55回）。

| | 大きさ | 欄の高さ |
|---|---|---|
| 授業名 | **16pt**（入らなければ縮む） | 8mm |
| 詳細・備考 | 7pt | 21mm（6行） |
| 放課後 | 8pt | 余りぶん（罫線 4.2mm） |
| 朝学習・業間などの休み行 | 9.5pt | 6mm |
| 週メモ | 6pt | 10mm |

### 印刷の寸法

`@page { size: B5; margin: 可変 }`。B5 は 182 × 257mm。
**貼り付け領域の実寸が未決（0節 a）なので、余白と印刷倍率を画面から動かせるようにした。**
1枚刷って手帳に当て、合う値を見つけたらその値を設定シートに書いて全職員で共有する。

**画面の拡大率と印刷の倍率は別の操作にしてある。** 1つにすると、読むために拡大した人が
そのまま刷って寸法を外す。

## 3. 層

5つある。

| 層 | 誰が | 何を入れるか | 範囲 |
|---|---|---|---|
| 基本時間割 | 教務 | 各クラスの平常時の時間割。**A週・B週の2種類** | 週案枠を開いた時に流し込む |
| 学校全体 | 教務・管理職 | 訓練・朝会・全校練習・休業日 | 全クラス |
| 学年 | 学年主任 | 校外学習・学年体育・学年集会 | その学年の全クラス |
| 専科 | 音楽・図工・理科・外国語などの専科 | 自分が持つ時間 | 自分が担当するクラス |
| 担任 | 担任 | 各教科・行事・給食・コアタイム | 自分のクラス |

**一括設定は層から自然に出る。** 教務として書けば全クラスに、学年主任として書けばその学年に入る。
別に「一括設定画面」を作らない。画面が1つ減り、覚えることも1つ減る。

### クラス編成は表から読む

学年でクラス数が違う。**5年・6年だけ4クラス、1〜4年は3クラス**（合計20学級）。
数をコードに書かない。本番では「クラス」シートが正本（1行1クラス：年度・学年・クラス）で、
画面の「学級編成」から直せる。

クラス名から学年を引くとき、**名前を「-」で割らない。**
学年を名前に持たないクラス（特別支援学級など）が入っても壊れないようにするため、
編成の表を逆に引く。

### 年度で丸ごう分ける

年度は 4/1 起点。**開いている週の日付から決まる。** 手で切り替えさせない——
切り替えを残すと、切り替えたまま別の年度に書く事故が起きる。週を動かせば年度も動く。

**前の年度は消さずに丸ごと残る。** 保存の形は

```
  years["2026"] = { classes, specials, base, weeks, week1 }
  years["2027"] = { … }
```

新しい年度は前の年度から **クラス編成と専科だけ**を引き継いで始まる
（学年ごとのクラス数は年で変わらないため）。
**基本時間割は引き継がない。** 毎年変わるものを黙って持ち越さない。
必要なら「前年度から写す」を押す。

### A週とB週

年間行事計画表の左端に「週」の欄があり、A と B が振ってある。基本時間割はこの2種類を持つ。
画面上部の `A週 / B週` がその週のどちらかを決め、流し込む基本時間割が切り替わる。
2つがほとんど同じなら「A週をB週へ写す」で写してから違うところだけ直す。

### 勝ち負けは時刻で決める。層では決めない

同じコマに2つ以上の層が書いたとき、**あとから書かれたほうが出る。**

*層の順で決めなかった理由*：層で決めると、上位がどれだけあとから入れても下位に負ける。
学年主任が水曜に「来週の火3は学年体育」と入れても、担任がすでに算数を入れていれば反映されず、
**しかも入れた学年主任自身の画面にも出ない**。これは黙って落ちる種類の誤りで、いちばん危ない。
時刻で決めれば、あとから直した人の意図がそのまま通り、それを担任がまた直せば担任が通る。
人が期待する順序と一致する。

（この欠陥は、プロトタイプを実際に動かして見つけた。層の順で組んだ初版は、
担任が先に入れたコマに学年主任が上書きできなかった。）

### 最新を見ていない保存は通さない

「あとから書かれたほうが出る」は、**書いた人が最新の状態を見ていたときの話**。
見ていない保存まで通すと、**書いた本人にも見えないまま**他人の予定が消える。

A先生が週を開き、そのあいだにB先生が同じコマを直し、A先生が古い画面のまま保存する。
A先生の画面にB先生の予定は一度も出ないので、消したことに誰も気づかない。
潰されたB先生への知らせ（「あなたの予定が上書きされています」）は出るが、
それは**消えたあとの知らせ**で、消える前に止めていない。

だからサーバは、そのコマを書く前に **`expectedAt`**（その編集を始めたとき、
画面が知っていたサーバの更新時刻）と、いまシートに入っている更新時刻を突き合わせる。
違えば**そのコマだけ書かずに返す**（`conflicts[]`）。画面は窓を出し、
教師が最新の内容を見たうえで選び直す。

- **既定は「最新の内容を見る」。** Esc も、窓を閉じただけのときも同じ。
  上書きは、そう答えたときだけ
- 上書きを選んだら、**いまシートに入っている時刻を `expectedAt` として送り直す。**
  「強制」の合図は作らない。作ると、見ないまま押す道がそこに残る
- 上書きを選んだときは、**週を読み直してから**、上書きの窓（既定「変更しない」）を
  改めて通す。あちらは**見えている予定**を潰すときの確認、こちらは
  **見えていない変更**を潰すときの確認で、原因が違うので1つにできない

*止めるのはコマ単位*：1回の保存に30コマ入っていても、食い違ったコマだけを止める。
全部止めると、貼り替えの途中で保存そのものができなくなる。

*`expectedAt` を送らない画面*：今までどおり書く。止めると、版が入れ替わる
数分のあいだ、全員が保存できなくなる。

*更新時刻が入っていない行*：1.3.0 より前に書かれた行と、人がシートに手で足した行は
更新時刻を持たない。これを「行がまだ無い」（0）と同じ扱いにすると、
新しいコマのつもりで 0 を送ってきた画面と一致してしまい、見ないまま上書きできる。
**-1 として区別する。** 層の重ね順に使う時刻は 0 のままにする——
負にすると、その行が基本時間割より下に沈んで画面から消える。

### 権限は分けない

**層は「どこから来たか」を示すだけで、誰が直せるかは分けない。** 上位から来たコマは
淡い塗りと右上のラベル（全体／学年／専）で示す。**塗りは色分けの上限に従って2色しか使わず、
層そのものはラベルの文字が運ぶ。** モノクロでも、色が見分けにくくても意味が残る。

*権限で止めなかった理由*：止めると、直前の変更（急な雨で校庭が使えない等）に担任が対応できず、
「システムに書いてある予定」と「実際にやったこと」がずれる。**ずれた記録は時数集計を壊す。**
エラーの少なさを優先するなら、直せるようにして誰が直したかを残すほうが安全。

### 上書きは、両側に知らせる

同じコマに2つ以上入るのは、**誰かの予定が消えたように見える**という点で危ない。
片側だけに知らせても足りないので、両側に出す。

**書く側**——書く前に1回だけ聞く。

```
  9/7(月) 2校時

  次の予定を「学年体育」に上書きします。

  　2-1 の「国語」（担任）
  　2-2 の「算数」（担任）

  つづけますか？
```

*聞く条件*：潰すのが**別の人の予定**のときだけ。
**基本時間割を直すときは聞かない**——それがふだんの作業で、毎回聞かれたら操作が止まる。
一度«はい»と答えたコマは、その画面を開いている間は聞き直さない。

**された側**——次に開いたときに知らせる。

```
  あなたの予定が上書きされています

  9/7(火) 3校時 が 国語 → 学年体育 に上書きされました
  学年が入れたもの
```

*見せる範囲*：**開いている面の持ちぶんだけ。**
担任には担任が入れたコマの上書きだけを出す。
自分に関係のない層どうしの重なりは出さない——読まれない警告は機能しない。

**同じ上書きについては1回だけ。** 中身が変わったら出し直す。
戻したいときは、そのコマをもう一度入れ直す（あとから書いたほうが出る）。

## 4. データの持ち方

正本は週案スプレッドシート1枚。**1行＝1コマ。**

| 列 | 中身 | 例 |
|---|---|---|
| `date` | 日付 | `2026-11-20` |
| `slot` | 時程行のID | `p2` |
| `class` | クラス | `3-3` |
| `title` | タイトル欄 | `算数` |
| `note` | 詳細欄 | `分数のたし算 ①` |
| `titleUrl` / `noteUrl` | それぞれの欄のリンク | `https://...` |
| `subject` | 時数を数えるための教科コード | `sansu` |
| `layer` | どの層が書いたか | `homeroom` |
| `teacher` | 担当者（専科のとき入る） | `ongaku@edu.nishi.or.jp` |
| `updatedBy` / `updatedAt` | 誰がいつ。**`updatedAt` が勝ち負けを決める** | |

書き込みは `LockService` で直列化し、**保存は差分だけ**送る。
そのシートの中では丸ごと書き戻すが、送るのは触ったコマだけなので、
同じシートを同時に開いている2人でも、触っていないコマは消えない。

### 打つたびには送らない。「保存」を押したときに送る

書いたコマの**場所だけ**を覚えておき、送る直前にそのときの中身を読んで
**1コマ1件**にする。3回直しても送るのは1件。

*そうした理由*：打鍵のたびに送ると、1コマ書くだけで何十件も送ることになる。
シートには一字ずつの途中経過が積まれ、回線が細い校内では打鍵が止まる。

押し忘れても消えないように、**週や画面を変えるとき・閉じるときは、押さなくても送る。**
手元（その端末）には打つたびに残している。

**送り切れないまま閉じられたぶんは、中身ごとこの端末に控える。**
次に開いたときに送り直し、送れたら控えを捨てる。
控えを送るのは、**週を読み直すより先**。あとから送ると、
読み直しで消えた中身を送ることになる。

*控えが要る理由*：閉じるときに送っても、届く前に画面が閉じることがある。
手元には中身が残るが、次に開くとシートの側を読み直すので、
**シートに無いものは上書きされて消える。**
「時間割の入力」の右の保存は、まだ入っていないコマの数を出し、
入っていないあいだは塗る。

### シート

**正本はシート。** 列は名前で引く（位置で引かない。列を1つ足しただけで全部ずれる）。

| シート | 列 |
|---|---|
| 設定 | キー・値・覚え書き（用紙／余白／倍率／時数コピーの形／例外で通すメール／外部ファイルID） |
| 時程 | ID・表示名・種別・時刻・時数表の列・教科を選べる |
| クラス | 年度・学年・クラス・担任メール・**たんぽぽ交流級**（**1行1クラス**） |
| 専科 | 年度・教科コード・表示名・メール |
| 教科 | コード・表示名・時数表の1文字・時数に数える |
| 基本時間割 | 年度・クラス・週(A/B)・曜日・時程・教科コード・表示名（**人が直接書く場所でもある**） |
| 週案 ◯（**1クラス1枚**） | 年度・日付・曜日・時程・題名・詳細・教科コード・層・対象・担当・更新者・更新時刻 |
| 年設定 | 年度・第1週の月曜 |

**週案は1行1コマ。書かれたものだけが行になる**（基本時間割どおりの週は0行）。
層と対象の組で1コマが決まる。

### 週案はクラスごとに1枚

```
  週案 3-3   … 担任が書いたもの・専科がそのクラスに入れたもの
  週案 3年   … 学年で入れたもの
  週案 全校   … 学校全体で入れたもの
```

*1枚に積まない理由*：担任がシートを開いても、どの行が自分のものか分からない。
20クラス×1年ぶんで数千行になり、目で確かめられない表は、
**間違いに気づけない表**でもある。

*専科のコマもクラスのシートに置く理由*：担任が自分のシートを見れば、
その週のすべてが載っている。専科のぶんだけ別の場所を見に行かせない。

**中は日付順・時程順に並べる。** 並べ替えはこちらがする（人が並べ替えない）。
書き込みは「丸ごと読む → 差し替える → 並べ替える → 書き戻す」。
**行番号を覚えない。**

*行番号を覚えない理由*：日付は、シートに書いた瞬間に日付型になる。
`2026-09-07` という文字のまま行を覚えると、次に読んだときは同じ行を見つけられない。
見つけられないと、直したつもりのコマが**新しい行として積まれていく**。
打鍵のたびに1行ずつ増え、消したコマは元の行が残る。実際にそうなった。

### 待っているあいだ、待っていると分かるようにする

校内の回線ではシートを1枚読むのに1秒前後かかる。**そのあいだ画面が黙っていると、
押せていないのかと思ってもう一度押す。** 遅さそのものより、こちらのほうが困る。

| どこ | 何を出すか |
|---|---|
| 画面の上端 | 細い帯が流れる。**どこを見ていても目に入る** |
| 左のメニュー | 週送り・A週B週・行き先の**すぐ下**に「3-2 をひらいています」「シートに保存しています」。**手を動かした場所のとなりに出れば、探さなくても目に入る** |
| 押したタイル | 押した場所そのものが応える |

**画面は止めない。** 止めると、開いたのに何も出ない時間ができる。
手元の控えで描いた紙は、待っているあいだも読める。
刷るときは出さない。

### 次のクラスを待たせない

1つ開いたあと、手が空いているうちに**この週の残りを読んでおく**。
開くたびに1往復待つのは、3クラス見るだけで3回待つということ。

先読みで読み直すとき、**まだ送っていないコマがある対象は触らない**。
触ると、書いたのに消えたように見える。

### コマの呼び名は「月曜から何日目か」

画面は `0|p1`（月曜の1校時）でコマを持つ。シートは日付で持つ。
**読んで返すときに、日付を「何日目か」に直す。**

*ここを外すと*：書いたものはシートに正しく入る。だが次に開いたとき、
画面は `0|p1` を探し、返ってきたのは `2026-09-07|p1` なので見つけられない。
**シートには入っているのに、画面では基本時間割に戻って見える。**
入っていないように見えて書き直すと、こんどは二重に入る。実際にそうなった。

形の取り決めなので、シート側の検査で字のまま押さえてある
（「何日目|時程 で返す」「日付のままのキーは返さない」）。
継ぎ目の検査でも、書く→送る→開き直す→出る、まで通しで見ている。

### 頼んだ先の週へ入れる

シートを読みに行ってから返事が来るまでのあいだに、**もう別の週を見ていることがある**。
返事を「いま見ている週」へ入れると、その週の中身が消える。
校内の回線では返事の順序が入れ替わるので、**古い週の返事があとから届く**。

頼むときに年度と週を覚えておき、返事はその週へ入れる。
「読み込みずみ」の印も、頼んだ先の週に付ける。

*ここを外すと*：今週を開いた直後に来週へ動かすと、遅れて届いた今週ぶんが
来週の中身を上書きし、**来週が空（基本時間割のまま）に見える**。
実際にそうなった。開き直すと直るので、原因が分かりにくい。

### 開いた画面に要るシートだけ読む

3-3 を開くのに要るのは `週案 3-3`・`週案 3年`・`週案 全校` の3枚。
27枚を毎回読むと、開くたびに数秒待つことになる。
全学年と専科だけは、どのクラスを潰すかを見せるために全部を読む。

```
  school  対象なし     grade   対象＝学年
  special 対象＝クラス  home    対象＝クラス
```

「クラス」「専科」は、**年度の欄が空の行を「どの年度でも使う既定」**として読む。
その年度の行が1つでもあれば、そちらが勝つ。年度が変わっても既定から始められる。

### 人が手で書いた行も読む

`基本時間割` は人が直接書く場所でもある。**機械が書いた形しか読めないと、
手で書き足した行が黙って無視される。** 入っていないのか読めていないのかが
画面から分からず、シートを見ながら何度も書き直すことになる。

| 欄 | 通す書き方 |
|---|---|
| 曜日 | `月`〜`金` ／ `月曜日` ／ `0`〜`4`（古い書き方） |
| 時程 | `p1`〜`p6` ／ `1`〜`6`（授業の行の上から数える） |
| クラス | `1-1` ／ 日付に化けた値も月-日から戻す |

**書くときは「月」と書く。** 0〜4 で書くと、隣の行にならって手で書き足した行が
読めなくなる。読めなかった行は捨てずに、何行目かを画面に出す。

### 入力ロック（画面ごと）

**押すまで、その画面からは直せない。** 見るだけのつもりで開いたクラスに、
うっかり字を入れてしまうのを止める。もう一度押すと外れる。

- 画面（クラス・学年・専科・全学年）ごとに持ち、**この端末に残る**
- 止めるのは**書き込みだけ**。読むこと・刷ること・時数を写すことは止めない
- **ほかの先生の画面は止めない。** シートには書かない、この端末の中だけの話

止める場所は `writeCell` の1か所。ここが書き込みの1本道なので、
引っぱって入れても、打っても、パレットを押しても入らない。
ボタンを暗くするのは**見て分かるようにするため**で、止めているのはそこではない。

### 消すときは行を消さない

コマを空にしたら、**その行の中身だけを消して行は残す。**
行を削除すると下の行番号がすべてずれ、同じ書き込みの途中で覚えた行番号が
別の行を指すようになる。空行は読むときに飛ばす。

### 勝ち負けの時刻はサーバが打つ

「最新の状態を見たうえで最後に書いたものが勝つ」（3節）の時刻は、**サーバが打った値が正**。
教師それぞれの PC の時計を信じると、時計が進んでいる人がいつも勝つ。
画面は自分の時計で先に描き、送ったあとに戻ってきた時刻で控えを直す。

### 書き込みはロックの中でまとめて

`LockService` の中で1回読み、差分の行だけを書く。
2人が同じ週を開いていても、片方の編集がもう片方の書き戻しで消えない。

## 5. 専科の表記反転

音楽専科が 2-1 の音楽を設定したとき、**データは1つ、見え方が2つ**になる。

```
  cell = { title:"音楽", subject:"ongaku", teacher:"ongaku@…", class:"2-1" }

  2-1 の担任の画面 →  音楽        （誰が来るかは決まっているので教科名でよい）
  音楽専科の画面   →  2-1         （どこへ行くかが知りたいのでクラス名）
```

判定は `cell.teacher === 開いている人` の1つだけ。専科が「自分の週で見る」を入れると、
持ちコマがクラス名で並ぶ。**専科は自分の画面から直接そのコマを直せる**（担任の画面にも即反映される）。

## 6. 年間行事計画表の取り込み

**取り込み用のシートを1枚もらう。** 元の表（`令和8年度 西宮市立高木北小学校 年間行事計画表`）は
3か月が横に並んでいて、月ブロックごとに5列（`週 / 日 / 曜 / 行事計画（児童） / 行事計画（職員）`）。
そのままでも読めるが、**読ませない。**

*理由*：3か月横並びは、月ブロックの開始列を1つ間違えると**別の月の行事が別の日付に静かに入る**。
落ちずに、間違った予定が週案に出る。いちばん気づきにくい壊れ方で、エラーの少なさに反する。

### もらう形

1行1日の縦長の表にして、`行事取り込み` という名前のシートに貼る。年度ぶんで約365行。

| 日付 | 週 | 行事計画（児童） | 行事計画（職員） |
|---|---|---|---|
| 2026-11-16 | A | 校外学習6年(奈良) | 職員会議15:00 |
| 2026-11-17 | | | 定時退勤日 |
| 2026-11-18 | B | ジャンボ落語・計画 | … |

- **日付の列があるので読み違えようがない。** 列を1つ間違えても、日付が合わなければ入らない
- `週` の `A` / `B` がその週の基本時間割を決める（3節）。空欄は前の週を引き継ぐ
- 見出しの語はこの4つ。順番も固定。色は無視する

### 校時への割り付けは自動化しない

行事は**日付にしか結びついていない**。「校外学習6年(奈良)」が何校時かは書いていない。
自動でコマに入れると、外れたものを毎週打ち消す作業が生まれる。**打ち消す作業は、
最初から入れない作業より必ず多い。**

取り込みは日付単位にとどめ、教務が「全学年」を開いて校時を決める。
週案の日付見出しにその日の行事が候補として出て、選ぶとコマに入る。

## 7. たんぽぽ時間割へ反映

### 実物の形

- **1シートに1週。** `C1` の週名（例「4月第2週」）が `AM2:AT56` の週マスタを引いて各曜日の日付を出す
- 1日ぶんが縦のブロック。各校時は2行で、**上が授業名、下が担当**（`交：丸山` / `た：桝村` / `支：大屋`）
- 列は**児童ごと**。同じ児童でも曜日によって交流学級が変わる（H列＝月「1-1」火「1-2」水「1-2」…）
- 同じ交流学級の列が複数ある（W・X が両方 3-1 など）
- AB列以降は**支援員・ボランティア**の列（大屋・丸山・日外・喜田・星川・秋山・内田・ボランティア×3）
- 担当のセルには**色が付いていて、色が支援員を表す**（赤＝大屋、黄＝丸山、青＝日外…）
- 交流学級名の表記が揺れている：`1-３` `２ｰ３` `３－２` `1-2` `１－１`（全角半角とダッシュ3種）

### 列は「たんぽぽの組」ごとに並べる

たんぽぽ児童は、**どのたんぽぽ組にいるか**で持つ。
`{"1":["1-3","3-2"], "2":["4-1"]}`。同じ組に同じ交流級を2つ入れれば2人（＝2列）。

出す先の列は **たんぽぽ1組の全員 → 2組の全員 → …**、組の中はクラス順（1-1〜6-4）。
たんぽぽ担当は組ごとに見るので、**クラス順に混ぜて並べると自分の組の児童を目で拾えない**。

**偶数の組は地の色で分け、組の境目に太い縦線を引く。**
地の色だけにしないのは、色覚型によっては灰と見分けられないため。
線は形の手がかりなので、色に関係なく効く。
色は青みの側へ振ってある（青がもっとも多くの色覚型で灰と分かれる）。
どちらも黒文字とのコントラストは 10:1 を超える。

「このサイトから入れたか（灰）／たんぽぽの中で受けるか（白）」の塗り分けとは**別の軸**。
前者は行、後者は列で表す。

### 交流級の見出しは Date に化ける

スプレッドシートは `1-2` を「1月2日」として取り込む。
**画面には `1-2` と出るのに `getValues()` は Date を返す。**
字として比べると交流級の列が1つも見つからず、1コマも書けない。落ちないので気づかない。

塞ぎ方は2枚（クラス名の列と同じ考え方。4節）。

1. 作る側（`buildTanpopo`）は、**値を入れる前に B列から右を「書式なしテキスト」**にする。
   A列は日付を入れるところなので掛けない
2. 読む側（`shapeTanpopo` / `exportTanpopo`）は、見出しを **`Sheets.asClass` で月-日から戻して**から比べる

### シートの形を1つだけ揃えてもらう

日ブロックの先頭行が **2・18・36・51・69** と不揃いになっている。行数は 16・18・15・18・18。
（水曜だけ短いのは6校時が無いため。ほかは空行が余分に入っている。）

**1日16行に揃える。**

| | 先頭行 | |
|---|---|---|
| 見出し | 1 | 取り扱い注意・週の選択・連絡 |
| 月 | 2 | 2〜17 |
| 火 | 18 | 18〜33 |
| 水 | 34 | 34〜49（6校時の2行は空でよい） |
| 木 | 50 | 50〜65 |
| 金 | 66 | 66〜81 |

ブロックの先頭からの相対行は**いまと同じ**。ここは変えない。

```
  +0  日付 ／ その日の交流学級
  +1  1校時 授業名     +2  担当
  +3  2校時 授業名     +4  担当
  +5  中休み
  +6  3校時 授業名     +7  担当
  +8  4校時 授業名     +9  担当
  +10 給食
  +11 昼休み
  +12 5校時 授業名    +13  担当
  +14 6校時 授業名    +15  担当
```

**揃えると 81 行になる。いまの 86 行より5行短い。**
B4 1枚に収めるのは、いまより楽になる。列は増やさない。

### 出す先の形は、こちらで作れる

**形が合わないと1コマも入らない。** 日ブロックの場所も列も決められないので、
「0日ぶん・0コマ」で終わる。手で整えるのは、決まりを覚えていないとできない。

| 操作 | すること |
|---|---|
| いまの形をみる | 何行×何列か、日付・骨・交流学級の見出しがあるかを**そのまま出す**。足りないものを名指しする |
| この形で作りなおす | 児童ごとに1列・1日16行×5日の形を作る。灰色と条件付き書式も入れる |

作りなおしても、**いまのシートは消さない**（名前を変えて残す）。
消してしまうと、たんぽぽ担当が書き足した担当者・場所が戻せない。

**日付は出すたびにこちらが入れ直す。** たんぽぽ時間割は毎週おなじシートを
使い回す。週が変わるたびに人が日付を打ち替えるのでは、打ち替え忘れた週に
何も入らない。骨（中休み）から日ブロックを見つけて、その先頭に日付を書く。

### 行数は決め打ちしない。骨を探して数える

**揃えてもらう前でも書ける。** 実物は日によって 16・18・15・18・18 行と
まちまちで、空行の入り方も揃っていない。揃えてもらうのを待つと、
そのあいだ1日も書けない。揃えたあとに誰かが行を足しても壊れる。

1. A列を上から見て、その週の日付が入った行を探す（先頭行の決め打ちはしない）
2. 次の日付までを、その日のブロックとする
3. ブロックの中から **「中休み」「給食」「昼休み」** の行を探す。この3つは骨で動かない
4. そこから校時の行を数える

```
  1校時 = 中休み − 4      2校時 = 中休み − 2
  3校時 = 中休み + 1      4校時 = 中休み + 3
  5校時 = 昼休み + 1      6校時 = 昼休み + 3      （いずれも授業名の行）
```

5. 骨が見つからない日は、**その日だけ書かない**。理由を添えて画面に出す
6. 短い日（水曜は6校時が無い）は、**ある校時だけ書く**。日ごと飛ばさない

形が合わない日に書くと、**別の校時の行に授業名が入る**。落ちないので気づかない。
探す往復は一瞬で、間違えたときの被害と釣り合わない。

### どこから出すか — 入口のいちばん下の「たんぽぽ」

**出す操作はたんぽぽの面に1つだけ置く。** ほかのクラスの画面には反映ボタンを置かない。

*そうした理由*：反映は「たんぽぽ時間割の1週ぶんを丸ごと入れ替える」操作で、
効く範囲は押した人の学級ではなく**たんぽぽ全体**。どのクラスの画面からでも押せると、
3-3 の担任が自分の週を直したついでに押し、ほかの交流級のぶんまで巻き込んで書き換える。
出すのはたんぽぽ担当の仕事なので、入口も1つにする。

面ですることは2つ。

1. **たんぽぽ児童がいる交流級と、その人数を選ぶ。** 押すたびに 0人 → 1人 → 2人 → 0人。
   人数は `クラス` シートの「たんぽぽ交流級」欄が持つ（年度ごと）。
   画面から選んでも、シートに直接書いてもよい。**正本はシート**（4節）。

   *人数を持つ理由*：**たんぽぽ時間割は児童ごとに1列。** 同じ交流級に2人いれば
   2列いる。書き込みは列の見出しを見て決めるので人数が無くても書けるが、
   **列が足りないときに気づけない**。1人ぶんが黙って入らないまま紙になる。
   出すときに人数と列の数を突き合わせ、合わなければ知らせる。
   実物の列見出しに出るクラスと、いま在籍している児童のクラスは、年度の途中でずれる。
   列見出しだけを頼りにすると、転出した児童の列にも入り続ける
2. **出す。** 選んだ交流級のぶんだけが入る

### 出す前に、まだ動いていないクラスを知らせる

| 状態 | 何が入っているか | 知らせ |
|---|---|---|
| `ok` | 担任か専科が今週このクラスに書いている | 出さない |
| `upper` | 全校・学年の予定だけ。**担任は未着手** | 「上位の予定しか入っていません」 |
| `base` | 何も無い。**基本時間割のまま** | 「今週まだ基本時間割のままです」 |

*知らせる理由*：基本時間割のままの週をそのまま出すと、
**担任がまだ書いていない予定を、本物の予定としてたんぽぽへ配ることになる。**
たんぽぽ担当はそれを見て支援員の配置を決めるので、あとから変わると配置ごとやり直しになる。
止めはしない（金曜までに全担任が書き終わらない週はある）。出す前に見えていればよい。

### 全部入れて、そのあとはたんぽぽ側で直す

**選んだ交流級の列は、全部入れる。** 空のコマも空のまま入る。
入れたあとは、たんぽぽ時間割の側を上書き編集していく。
このサイトは**下書きを1週ぶん配る役**で、完成させる役ではない。

| | 書く | 書かない |
|---|---|---|
| 選んだ交流級の列 | **全部**（担当者・場所が `交：` `た：` `支：` 空、どれでも） | |
| 選んでいない交流級の列 | | 触らない（たんぽぽ児童がいない） |
| 編成に無いクラスの列 | | 触らない（`クラス` シートかたんぽぽの列見出しが古い。画面に出す） |
| 支援員・ボランティアの列（AB以降） | | 触らない（交流学級ではないので引く元が無い） |
| 担当者・場所の行 | | **触らない**（たんぽぽ担当が書いている。支援員の色分けもここに乗っている） |

*空のコマも入れる理由*：前は「こちらが空のコマには書かない（足すだけ）」としていた。
足すだけにすると、**先週の授業名が残ったままのコマと、今週入れたコマが混ざる。**
紙の上で見分けが付かないので、たんぽぽ担当は結局全部を確かめ直すことになった。
1週ぶんを丸ごと入れ替えれば、紙に載っているのは常にこの週のものだけになる。

*代わりに失うもの*：**たんぽぽ側で直した内容は、次に出したときに消える。**
これは承知の上の取り引きで、だから出す前に必ず聞く（下記）。

### 塗りは、こちらが塗らない

| | |
|---|---|
| **灰色 `#DCDCDC`** | このサイトから入れたコマ |
| **白 `#FFFFFF`** | たんぽぽの中で受ける授業（担当者・場所の**左端が「た」**） |

この塗り分けは、**たんぽぽ時間割の側の条件付き書式が決める。**
条件は「すぐ下の担当者・場所のセルが `た` で始まるか」。こちらは値だけ入れる。

*こちらが塗らない理由*：入れたあとにたんぽぽ担当が担当者・場所を `交：` から `た：` へ直す。
こちらが塗った色は直した瞬間に古くなり、**色と中身が食い違う。**
シートが自分で塗れば、担当者・場所を直した瞬間に色も追いつく。

*色相を使わない理由*：**この塗り分けはモノクロ印刷で読むためのもの。**
色で分けると、白黒で刷った時点で区別が消える。明るさの差だけで組む。

*`#DCDCDC` にした理由*：白との明るさの差が 1.4 倍あり、黒い字は 12.7:1 で読める。
`#F2F2F2` まで薄くすると差が **1.1 倍しかなく、トナーを節約する設定のプリンタや
白黒コピーで消える**（実測して落とした）。

*授業名の字で判断しないことにした理由*：以前は「`た` で始まる**授業名**は触らない」としていたが、
これは**書いてある字から意図を推し量る**やり方で、`たしかめ` のような語で誤る。
見るのは担当者・場所の行。たんぽぽ担当が毎週その意図そのものを書いている。

### 反映の規則

| | |
|---|---|
| 出せる場所 | **たんぽぽの面だけ。** ほかのクラスの画面には置かない |
| 対象 | その面で選んだ交流級。1つも選んでいなければ出せない |
| ブロックの位置 | A列の日付を探して起点にする |
| 校時の行 | **「中休み」「給食」「昼休み」の行を探して、そこから数える。** 行数を決め打ちしない |
| 形が合わない日 | その日だけ書かない。**理由を添えて画面に出す** |
| 短い日（6校時が無いなど） | **ある校時だけ書く。** 日ごと飛ばさない |
| 列 | **ブロックごとに見出しを読み直す。** 曜日で交流学級が変わるため |
| 対象列 | 見出しを正規化して「学年-組」になり、かつ**選んだ交流級**の列だけ |
| 正規化 | NFKC のあと `- ‐ ‑ – — ― ー − ｰ －` をすべて `-` に寄せる |
| 書く行 | **タイトル（授業）の行だけ。** 担当者・場所の行には触れない |
| 書く条件 | **無し。選んだ交流級の列は全部書く**（空のコマは空で書く） |
| 書かない | 支援員・ボランティアの列／選んでいない交流級／編成に無いクラス／給食・昼休み・中休みの行 |
| 塗り | **こちらは塗らない。** シート側の条件付き書式が担当者・場所を見て決める |
| 書式 | 値だけ入れる。**担当者・場所の行の色（支援員の色分け）には触れない** |
| 確定 | 何クラス・何セル入るかと、**たんぽぽ側の直しが消えること**を出し、1回押して確定 |

### 何が置き換わるか

「変更する場所」シートに書いてある運用はこうなっている。

```
  木曜日16:30までに、各担任に週案をもらう
  金曜日の朝までに入力（できれば・・・）
  金曜日中に、井上が打ち替え→印刷
```

**この打ち替えが反映ボタン1つになる。** 担任は自分の週案を書くだけで、集める工程が消える。

## 8. 時数集計表へコピー

週ごとに別のシート（タブ名＝週番号）。**クラスが縦に並び、時程が横**。

```
        週 │ 朝   1校時  2校時  中  3校時  4校時  昼  5校時  6校時 │ メモ
  7/13 3-1│ 国    国     学        算     図                      │
   (月) 3-2│ 国    社     総        体     算                      │
       3-3│ 国    国     学        道     国                      │
       屋島│                                                      │
       （空き行）
  7/14 3-1│ …
```

- **1シート1週。** 曜日ごとにブロックが縦に並ぶ
- 教科は**1文字**（国 社 算 理 生 音 図 家 体 道 外 総 学）
- 一部のセルに `=IF($A$1="A",Top!X14,Top!X67)` の式が入っている
  （A週/B週で基本時間割シートから引いている）

### 1回で貼れる1つの矩形にする

コピーは**空のセルを含む1つの矩形**にする。曜日ブロックの隙間も空文字で埋めてある。
左上のセルを1つ選んで貼れば、5日ぶんが一度に揃う。

**時数に数えない教科（行事・給食・クラブ・委員会）は空にする。**
Excel 側は文字の出現数を数えているので、書くと集計が増える。

**列のずれは画面から直せる**（0節 b）。実物の列位置が確定していないので、
`朝=0 / 1校時=2 / 2校時=4 / 中=6 / 3校時=7 / 4校時=9 / 昼=11 / 5校時=12 / 6校時=14` を
初期値に置き、1回貼ってずれていたら直す。直した値は保存される。

### 貼ると式が消える

矩形の中に `=IF($A$1="A",Top!…)` の式があれば、貼った時点で値に置き換わる。
**これは承知の上での置き換え。** この仕組みが正本になれば、A週/B週の流し込みは
こちら側（3節）が持つので、Excel 側の式は要らなくなる。

*Excel を GAS から直接書かない理由*：OneDrive／SharePoint 経由の書き込みは認証も同期も
壊れやすい。人が1回貼るほうが確実で、操作も1つしか増えない。

### 3列。左＝操作／中＝紙だけ／右＝入れるもの

```
┌──────────────┬────────────────────────┬────────────────┐
│ 週案          │                        │ 時間割の入力    │
│ ◀ 9/7→9/11 ▶ │                        │ ┌────────────┐ │
│ 第23週 A週B週 │                        │ │教科・行事の │ │
│ [3-3 ▾]      │      白い紙            │ │ボタン      │ │
│ ─────       │   （上下に何も無い）    │ └────────────┘ │
│ ほかの週案    │                        │ 選んでいるコマ  │
│ 印刷／時数    │                        │ 教科名・行事名  │
│              │                        │ 詳細・備考      │
│ ─────       │                        │ リンク（複数）  │
│ 基本時間割    │                        │ 入れる先        │
│ 学級編成      │                        │                │
│ 凡例          │                        │                │
└──────────────┴────────────────────────┴────────────────┘
```

**上に帯を置かない。紙の上下にも何も置かない。**
週の移動も凡例も左へ寄せてある。紙の上下に1つ置くたびに紙が縮み、
いちばん見たいものが小さくなる。

**白い紙に出ているものだけが刷られる。** まわりは全部、刷られない面。
地の明るさで分けてあるので、「これは印刷に出るのか」を毎回考えずに済む。

紙は**画面に合わせて自動で拡大縮小する**（既定で入）。
**画面の大きさと印刷の倍率は別の操作**にしてある。1つにすると、
読むために拡大した人がそのまま刷って寸法を外す。

### 入口 — この表がそのまま層になっている

「週案をひらく」で出るグリッド。

**入口に週の表示は置かない。** 週・年度・A週B週は左のメニューにある。
同じものを2か所に置くと、どちらを見ればよいかを毎回考えることになる。

```
        ┌──────┬──────┬──────┬──────┐
  1年   │ 1-1  │ 1-2  │ 1-3  │      │
  …                                   │
  5年   │ 5-1  │ 5-2  │ 5-3  │ 5-4  │   ← 5年・6年だけ4クラス
  6年   │ 6-1  │ 6-2  │ 6-3  │ 6-4  │
  全学年 │ 音楽  │ 図工  │ 理科  │ 外国語 │
  たんぽぽ│ 交流級 3 クラスを選んでいる       │  ← ここでだけ、たんぽぽへ出す
        └──────┴──────┴──────┴──────┘
```

| 開いたもの | どこに入るか | 層 |
|---|---|---|
| `3-3` | そのクラスだけ | 担任 |
| `3年` | 3年の全クラス | 学年 |
| `全学年` | 全クラス | 学校全体 |
| `音楽` `外国語` など | 自分の週。コマにクラスを入れると、そのクラスに入る | 専科 |

**「だれとして書くか」を別に選ばせない。** 開いたものが層を決める。
役割の選択を残すと、「いま何として書いているか」と「どの週案を見ているか」の
2つを同時に覚えることになる。1つに畳めるものを2つ持たない。

入口に戻らず切り替えられるよう、中央の帯にも同じ並びのセレクトを置いてある。

### マスターを開いたときは、その層のものだけを出す

`3年` を開くと、学年が入れたコマだけが出る。担任が各クラスで入れたものは出さない。
混ぜると、いまどのクラスのものを見ているのか分からなくなる。
代わりに、**学年が入れたコマを誰かが上書きしていたら「3組が変更」と出る。**

### 学年・全学年には「リセット」を出す

学年や全学年で入れたコマは、その学年の全クラスに降りる。
**入れるのと同じ手数で取り消せないと**、間違えて降ろしたものを
1コマずつ空にして回ることになる。

教科の並びの終わりに、赤い「リセット」を1つ置く。教科と同じように
引っぱって落とせる。落としたコマを**その層から取り消すだけ**で、
各クラスが自分で入れたものは消さない（取り消すと、そちらが出るようになる）。

担任の画面には出さない。そちらは「上位に戻す」が同じ役をする。

### 教科は引っぱって入れる

右上に教科・行事のパレットを置く。**コマへ引っぱって落とすと入る。**
コマを選んでから押しても入る（引っぱれない場面のため両方残す）。
打って変換して確定する3手が、つかんで落とす1手になる。
専科の週では、パレットに並ぶのは教科ではなく**クラス**（行き先）。

### リンクは文字に付く。いくつでも

コマの中身は「文字＋リンク」を持つ。**欄の中で文字を選んでからボタンを押す**と、
その文字がリンクになる。1つのコマにいくつでも付く（題名にも備考にも）。
**紙の上でその文字を押すと開く。** 刷ると下線だけが残り、URL は刷らない。

持ち方は `<a>` だけを許した HTML。文字を打ち直してもリンクが文字に付いて動く。
*文字数の位置でリンクを持たない理由*：前を1字消しただけで全部ずれる。
`http`/`https` 以外の `href`（`javascript:` など）は読み込みの時点で落とす。

### 入れる先はコマごとに選ぶ。選ぶたびに戻る

クラスを開いているとき、そのコマだけを学年や全校へ広げられる
（`この学級のみ` / `この学年に反映` / `全校に反映`）。
**別のコマを選んだ時点で「この学級のみ」へ戻る。** 持ち越すと、
次のコマを直したときに気づかないまま全校へ広がる。

### 教科ごとの色分けはしない

塗りで見分けられるのは2色まで。その2枠は**上位から降りてきた**と
**重なっている**に使っている。どちらも読んでも分からない情報。

教科ごとに淡い地を4色置く案は測って落とした。
1型で 青×緑 が ΔE 12.8、2型で 青×紫 が 0.5、3型で 緑×黄 が潰れる。
凡例を出せば「色で区別できる」という約束になるが、その約束を守れない。
教科はセルの文字が言っているので、色で言い直す必要もない。

### 認知的負荷をどこで下げたか

| 手 | 何が減るか |
|---|---|
| 基本時間割を流し込む | 担任の入力が「週30コマ」から「変えた数コマ」になる |
| 入口のグリッドが層そのもの | 「学年一括設定」の画面も「だれとして書くか」の選択も要らない |
| マスターはその層のものだけ出す | どのクラスを見ているのか迷わない |
| 教科をパレットから引っぱる | 打つ・変換する・確定する の3手が、つかんで落とす1手になる |
| リンクを文字に付ける | 「どれが何のリンクか」を別に覚えない。押す場所が答えそのもの |
| 休み行に「5日とも同じにする」 | 給食・そうじを5回打たずに済む |
| 上位を淡い塗り＋ラベル | 「これは自分が決めたことか」が一目で分かる |
| 重なり警告を開いたとき1回だけ | 毎回出る警告は読まれなくなる |
| 専科の表記を見る人で変える | 担任は「音楽」、専科は「2-1」。どちらも読み替えが要らない |
| 紙を画面に自動で合わせる | 開くたびに拡大率を触らずに済む |
| 年度を日付から決める | 年度の切り替え忘れが起きない |

## 10. 誰が入れるか

**教職員だけが使う。児童は弾く。**

```
  教職員   なまえ@edu.nishi.or.jp
  児童     12345678@kyoiku.edu.nishi.or.jp
```

### 児童のドメインは教職員のドメインを末尾に含んでいる

これがこの節の全部。次の書き方はすべて**児童が素通りする**。

```js
email.endsWith("edu.nishi.or.jp")        // 児童も通る
email.indexOf("edu.nishi.or.jp") >= 0    // 児童も通る
/edu\.nishi\.or\.jp$/.test(email)        // 児童も通る
```

`@` の右側を切り出して**完全一致**で比べる。下位ドメイン（`sub.edu.nishi.or.jp`）も通さない。
2枚目として、`@` の左が8桁の数字なら（ドメインが万一同じでも）止める。

### 判断がつかないときは通さない

メールが取れない・形がおかしい、はすべて「通さない」。
ウェブアプリを「自分（置いた人）として実行」で置くと、**別ドメインの利用者では
`Session.getActiveUser().getEmail()` が空を返す**。児童が別テナントにいる場合ここに落ちるので、
「空＝通さない」でなければ児童が入れてしまう。

裏返しとして、教職員が別ドメインのアカウントで開くと弾かれる。これは正しい動きで、
弾かれた画面に「先生のアカウント（@edu.nishi.or.jp）で開いてください」と出る。

### 関門は3つ要る

| | 何を防ぐか | これが無いと |
|---|---|---|
| 1 | `doGet` で画面を見せない | 児童が週案を読める |
| 2 | **サーバ関数すべての1行目で `Gate.check()`** | URL を開ける人が `google.script.run` で直接データを取れる。**画面を出さないのは目隠しであって関門ではない** |
| 3 | **スプレッドシートを児童に共有しない** | アプリを迂回して元のシートを直接開ける |

**3 がいちばん忘れられやすい。** 共有は「特定のユーザー（教職員のみ）」にする。
ウェブアプリは「自分として実行」なので、他の教職員もシートへの権限は要らない。

デプロイ設定の `access: DOMAIN`（組織内の全員）は、**児童が同じテナントにいれば児童も含む**。
入口を絞っているのは `Gate.gs` であって、この設定ではない。

**例外は教職員ドメインの中でしか効かない。** 児童のアドレスを書いても通らない。

## 12. ソースの置き方

Apps Script のウェブアプリは、モジュールもバンドラも使えない。
だから **`src/` は人が読める単位で分けておき、`build.py` が1枚に畳む。**
畳んだものが `dist/index.html`（ブラウザで開ける）と `gas/plan.html`（Apps Script に貼る）。

```
src/
  index.html        画面の骨組みと @include の並び順
  css/tokens.css    色。**識別に使う色はここだけ**（実測して決めた値）
  css/app.css       画面の外側（刷られない面）
  css/sheet.css     紙（刷られる面）。**印刷の版面はここだけを見る**
  js/config.js      時程・教科・編成の既定値
  js/util.js        文字とリンクと日付の道具（状態を持たない）
  js/store.js       保存・年度・週
  js/compose.js     層の合成と書き込み。**いちばん大事な決まりがここ**
  js/sheet.js       紙を描く
  js/panel.js       右の入力パネル
  js/gate.js        入口と行き来
  js/tanpopo.js     たんぽぽの面（交流級を選ぶ・出す・プレビュー）
  js/dialogs.js     窓（基本時間割・学級編成・用紙・時数・たんぽぽ）
  js/main.js        起動と結線。**DOM のイベントを束ねるのはここだけ**
```

依存は上から下へ一方向。`config → util → store → compose → sheet/panel/gate/dialogs → main`。
`js/` の各ファイルは、自分より上のものだけを呼ぶ。

**`dist/` と `gas/plan.html` は直さない。** 直すのは `src/`。

```
python3 build.py          生成する
python3 build.py --check  生成物が src と一致するか調べる
node tools/check.mjs      画面を動かして確かめる（174件）
node tools/wirecheck.mjs  本番の口とのやりとりを確かめる（132件）
node gas/storecheck.js    シートの読み書きを確かめる（230件）
node gas/gatecheck.js     関門を確かめる（26件）
node gas/apicheck.js      関門の呼び忘れ・呼び先の行方不明を見る（57件）
```

### 版

`VERSION` に版と日付を書き、`build.py` が `APP_VERSION` / `BUILD_DATE` として
生成物に埋める。**ビルドした日を自動で入れない。**
入れると、src が1文字も変わっていないのに生成物が日ごとに変わり、
`build.py --check` が翌日から落ちる。版は上げる人が手で書き替える。

出た版は、左メニュー下の「管理・システム」に出る。
**不具合の連絡は、その窓の1行をそのまま貰う**（版・つないでいる先・年度が1行に入っている）。

### 手元と本番の継ぎ目

画面は**どちらで動いているかを知らない**。`src/js/backend.js` が吸収する。

| | 手元（`dist/index.html` をブラウザで開く） | 本番（Apps Script のウェブアプリ） |
|---|---|---|
| 置き場所 | localStorage | シート |
| 読み | 何もしない（メモリがそのまま正本） | 開く年度と週を1回読んでメモリに載せる |
| 書き | db を丸ごと書き出す | **差分を貯めて 0.6 秒後にまとめて送る** |
| 時刻 | 自分の時計 | サーバが打った値で控えを直す |

**1コマ打つたびにサーバを待つ作りにしない。** 校内の回線では打鍵が止まる。
週を1回読んでメモリに持てば、描画は今までどおり同期でよい。

一度読んだ週は読み直さない。画面を閉じるときは、貯めた差分を出し切ってから閉じる。
送れなかったぶんは捨てずに貯め直し、画面に出す。

### 速さのために決めたこと

| | |
|---|---|
| `Y()` は保存しない | 描画のたびに呼ばれる。年度を新しく作ったときだけ、呼んだ側が1回書く |
| マスターの「誰が変更したか」は `compose` を回さない | 週の表を直に引く。コマ数×クラス数の掛け算を避ける |
| セルは中身が変わったときだけ書き換える | 同じ字を入れ直すとカーソルが先頭へ跳ぶ |
| 打鍵中の欄だけ塗り直しから外す | 「フォーカス中は触らない」にすると、パレットで入れても字が変わらない |

### 壊れにくさのために決めたこと

| | |
|---|---|
| 保存できなかったら**画面に出す** | 黙って飲み込むと、書けたつもりで書けていないまま週が進む |
| 読めない保存データは**退避してから**初期状態で開く | 壊れた中身の上に上書きしない |
| `href` は `http`/`https` だけ通す | 貼り付けから `javascript:` が入らない |
| クラス名から学年を引くとき名前を割らない | 編成の表を逆に引く。特別支援学級のような名前でも壊れない |
| **クラス名の列を書式なしテキストにする** | `1-1` は「1月1日」として取り込まれる。打っても書いても同じ |
| **化けたクラス名は月-日から戻す** | すでに化けているシートでも読める（1月1日 → `1-1`） |
| **たんぽぽ時間割の見出しも同じ道を通す** | `1-2` が Date で返る。字として比べると交流級が1つも見つからず、1コマも書けない。落ちないので気づかない |
| **作る側は先に「書式なしテキスト」にする** | B列から右だけ。A列は日付を入れるところなので掛けない |
| 日付かどうかを `instanceof` で見ない | 実行環境をまたぐと必ず外れる。`getMonth` を持つかで見る |
| 上書きは書く側にも、された側にも出す | 片側だけだと「消えた」ように見える |
| **上書きの窓の既定は「変更しない」** | `confirm` は Enter で「はい」に落ちる。打鍵の勢いで他人の予定が消える |
| **層と人を別に持つ** | 前は同じ欄に層の名前を入れていたので、他人の予定かどうかを判定できなかった |
| 自分が入れたコマでは聞かない | 自分の予定を直すたびに窓が出ると、読まずに閉じる癖がつく |
| 誰が入れたか分からないコマは**他人に倒す** | 自分だと決めつけると、黙って上書きする側に転ぶ |
| **消さずに退避する**（`Sheets.stash`） | 消すと「前はこうだった」を誰も確かめられない。教員が自分で戻すこともできない |
| **形が分からない外部シートには書かない**（`Sheets.shapeOk`） | 書くと別の行に授業名が入る。落ちないので誰も気づかない |
| 失敗を「エラーが発生しました」で終わらせない | どのファイルの、何が、どう足りないかを必ず言う（`Sheets.shapeError`） |
| クラスを編成から外すとき、**書き込みが残っていれば知らせる** | 消えたように見えて残っている状態を作らない |
| **サーバ関数の関門は自動で見る** | 1つ書き忘れれば、そこが児童の抜け道になる。人の目では落ちる（`gas/apicheck.js`） |
| **本番では古い週の控えを捨てる** | localStorage は5MB前後で溢れる。次項 |

## 13. 何年も使ったときに、どこから壊れるか

30人が6年使う前提で数えた。**壊れる順に並べてある。**

### 13-1. 手元の控え（localStorage）── 2年目に溢れる ← 対処済み

1クラス週30コマで、この端末の控えは **1年で 2.72MB、2年で 5.4MB**。
localStorage の上限は 5MB 前後なので、**2年目に必ず溢れる**。
溢れると保存が黙って止まる（画面には赤い帯を出しているが、打ち続ける人は見ない）。

対処：**本番では古い週の控えを間引く**（`src/js/store.js` の `pruneWeeks`）。

- 平常時は、いま見ている週から近い順に `KEEP_WEEKS`（60週）だけ残す
- 溢れたときは、その場で間引いてもう一度書く。それでも駄目なら12週まで削る
- **手元だけで使っているときは1週も捨てない。** そこでは localStorage が正本
- **まだ送っていないコマがあるときは何も捨てない。** 送る前に捨てると、
  書いた本人にも見えないまま消える

捨てた週はシートに残っているので、その週を開けば読み直される。

### 13-1b. 年度の変わり目 ── 4月に「自分のクラスが無い」

クラス・担任・専科・時程・基本時間割・年設定・たんぽぽ・週案シートのどれか1つが
欠けたまま4月を迎えると、担任は**開いてから初めて**気づく。
30人が同じ週に同じことを聞きに来る。

対処：**管理・システムに「この年度を検査する」を置いた**（`Store.checkYear`）。
8項目を見て、足りないものを「要る／見る／よい」の3段で名指しする。

**直さない。** 直すところまで自動でやると、直した中身が誰にも見えないまま
年度が進む（誰がいつ何を入れたのか、後から辿れなくなる）。

### 13-1c. 30人が同じ週を触る ── 「消えた」と言われる

勝つのは最後に書いたもの。層は勝ち負けを決めない（3節）。
つまり**誰でもどのコマでも潰せる**。潰されたほうには次に開いたときに知らせが出るが、
潰す側が気づかずに潰し続ける形は残っていた。

対処その1：**上書きの窓を、既定「変更しない」にした**。

- ブラウザの `confirm` をやめた。Enter で「はい」に落ちるので、
  打鍵の勢いのまま他人の予定が消える
- 「変更しない」を左に置き、開いた瞬間そこに焦点を当てる。
  Esc も、窓を閉じただけのときも「変更しない」に落ちる
- **編集そのものは止めない。** 止めると、担任が直せないコマができて、
  直せる人を探して回ることになる（「誰でもどのコマでも直せる」を崩さない）
- 基本時間割の上書きでは聞かない。ふだんの作業なので、聞くと窓が鳴りやまない
- **自分が入れたコマでも聞かない。** そのために、更新者を層の名前から
  メールに変えた（シートの「更新者」と同じ形）。分からないときは他人に倒す

この窓は**見えている予定**を守る。見えていない変更は守れない。
週を開いたあとに誰かが直したコマは、画面に一度も出ないまま消える。

対処その2：**古い状態からの保存を、サーバで止める**（3節「最新を見ていない保存は
通さない」）。止めたコマは窓に出し、既定は「最新の内容を見る」。
2つの窓は別に出す。原因が違うので、教師が読んで判断できる形にならない。

### 13-2. 週案シートの行数 ── 6年で 7,200 行 ← 対処済み

1クラス週30コマ・年40週で、1クラスのシートは年1,200行、**6年で7,200行**。
`writeCells` はシートを全面書き戻すので、1回の保存で最大 **86,400 セル**を書く。
年数に比例して伸びる。

対処：**年度末に、その年度を退避する**（次項 13-2b）。
1クラスのシートは常に1年ぶん（約1,200行）で止まり、
書き戻しは 1,200行×12列＝**14,400セル**。6年後も同じ。

**ファイルは分けない。** 分けると、いま動いている運用（1ファイル・年度は行で持つ）を
壊す。分ける日のために入口だけは1か所に寄せてある。

```
Sheets.book()      いま開いているファイル。ここだけを差し替えれば年度別にできる
Sheets.bookName()  管理・システムに出す名前
```

**分ける基準**：保存が **2秒**を超えたら着手する。退避を毎年やっていれば、
そもそもここへ到達しない。

**測ってある。** `writeCells` が、ロック待ち（`waitMs`）と書き込み（`ms`）を
分けて返す。画面は直近20回ぶんを持ち、**いちばん遅かったぶん**を
「管理・システム」に出す（平均は、たまに出る遅さを隠す。困るのは
「たまに10秒待つ」ほうで、平均が速いことではない）。
待ちと書き込みを分けて測るのは、木曜の夕方に伸びるのが待ちのほうだからで、
混ぜると、どちらを直せばよいのか分からなくなる。溜め込まない
（大きな監査ログは作らない。作れば作ったで誰も見ない）。

着手するときの順は、

1. `Sheets.gs` に残っている `SpreadsheetApp.getActive()` を全部 `book()` に寄せる
2. `book()` に年度を渡し、年度→ファイルIDの対応を「設定」シートに置く
3. 前年度のファイルは**読めるまま残す**（消さない・移さない）

### 13-2b. 年度の退避 ── 年に1回・10分

**年度末に、人がドライブでファイルを丸ごと複製する。**
プログラムは「数える」「照合する」「消す」の3つだけをやる。

**本体のURLは変わらない。** 新年度も、教員は今までと同じURLを開く。
複製したほうが保管庫になる。教員へのURL貼り替えという年1回の事故源を作らない。

| | 中身 | 誰が開く | URL |
|---|---|---|---|
| 本体 `週案 2026年度` | 現役。年度末に前年度の行だけ消える | 教員30人（ウェブアプリ） | **ずっと同じ** |
| 保管庫 `週案 保存 2025年度` | 複製した時点の丸ごとの写し | 管理者だけ、シートを直接 | 毎年増える |

**複製をコードで書かない。** 書かなければ、コピー漏れが原理的に起きない。
Drive への書き込み権限も要らない。人の手のほうが安全で、速い。

手順は4段。**段ごとに別のボタンにしてある。1つにまとめない。**
まとめると、確かめずに消せてしまう。

| 段 | すること | 書くか |
|---|---|---|
| ① 数える | シート枚数・行数・コマ数・日付の範囲を出す | 読むだけ |
| ② 複製する | 人がドライブで「コピーを作成」し、URLを貼る | — |
| ③ 照合する | シートごとに行数とコマ数を突き合わせる | 読むだけ |
| ④ 消す | 年度を打ち込ませてから、その年度の行だけ消す | 書く |

止める条件（どれか1つでも当たれば、**1行も消さない**）。

- 貼られたURLが、いま開いているファイルそのもの（同じIDを貼る事故）
- 退避先を開けない（共有されていない）
- 退避先に、その年度の行が無い
- シートごとの行数・コマ数が合わない
- **③を押してから④を押すまでのあいだに、その年度の行が変わった**
  （④の中でもう一度数え直す。そのあいだに書かれたぶんは退避先に入っていない）
- 年度を打ち込んでいない（誤クリックで消えない）

消すのは**週案シートの、その年度の行だけ**。シートも見出しも消さない。
基本時間割・クラス・専科は残す（「前年度から写す」がそのまま使える）。
記録は `退避` シートに残す（年度・退避先URL・退避日・退避した人・行数・コマ数）。

**退避ずみの年度を開いたら、黙って紙を出さない。**
週案の行はもう本体に無いので、基本時間割だけの紙が出る。
それを黙って出すと「週案が全部消えた」と言われる。
紙の外に帯を出し、いつ誰が退避したかと、保管庫へのリンクを添える
（刷るときは消える）。**退避そのものより、この表示のほうが重要。**

`退避` シートは、`年設定` に列を足す形にしていない。`Sheets.head` は列が1つ
足りないだけで例外を投げるので、列を足した版を貼った瞬間、まだ列を足していない
学校では全員が立ち上がらなくなる。**新しいシートなら誰も壊れない**
（`setup` は無いシートを作るだけで、あるシートには触らない）。
古い学校ではまだ `退避` シートが無いので、読むほうは `Sheets.readAllSoft` を使う。

### 13-3. 木曜夕方の集中 ── ロック待ち

`writeCells` は `LockService` で直列化している。30人が同じ時間に保存すると、
1人1秒でも最後の人は30秒待つ。`waitLock(30000)` の上限にあたる。

いまは「保存ボタンを押した人だけが書く」形なので、同時に押される確率は下がっている
（打鍵のたびに送っていたころとは違う）。**部分更新に手を入れるのは、
保存が2秒を超えてから**。速くする改造は、必ず正しさを削る方向に働く。

### 13-4. 先読み ── 開いた週の27枚

`targetsForView()` で開いた画面に要るシートだけ読み、残りは開いたあとに先読みする。
年数が経ってシートが厚くなると、この先読み1回が重くなる。
13-2 と同じ基準（保存2秒）で見直す。
