# たんぽぽ時間割の教師名転記

出力先のスプレッドシートに「教師わりあて」という名前のシートを用意します。
週時間割と同じ行・列の配置で、授業直下のセルに担任名や支援員名を入力してください。
例えば月曜1校時の授業がB3なら、教師名は「教師わりあて」のB4に置きます。
児童列の並びを変更したときは、参照シートの配置も合わせてください。

出力時に各授業直下の同座標から表示文字を読み、週シートへ転記します。
対象はB列以降の出力列（児童列・設定された支援員列）で、5日×6校時です。
空欄・参照シートの範囲外は空欄となり、授業行や休み時間の行は転記しません。
数式がある場合も、その時点の表示結果を文字として転記します。

出力後は「田中」を「た:田中」に手入力で編集できます。参照元は変わりません。
同じ週を再出力すると、前の週シートは手入力を含め別名で退避され、
新しい週シートには参照元の最新の文字が転記されます。手入力の自動引継ぎはありません。

「教師わりあて」がないときは、既存の週シートを退避・変更する前にエラーを表示します。
参照シートを守るため、出力名に「教師わりあて」は指定できません。

導入時は更新した gas/Store.gs を校務側GASに反映し、利用中のウェブアプリの
デプロイを更新してください。GitHubのマージだけでは本番GASは更新されません。
